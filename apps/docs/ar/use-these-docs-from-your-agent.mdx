---
title: استخدم هذه الوثائق من وكيلك
description: امنح وكيلًا هذه الوثائق عبر MCP أو ملف نصي عادي.
---

لهذه الوثائق خادم MCP خاص بها. في <bdi>Claude Code</bdi>:

```bash
claude mcp add --transport http todz-docs https://docs.todz.app/mcp
```

للوكيل الذي يقرأ النص العادي، [todz.app/llms.txt](https://todz.app/llms.txt) يسرد الصفحات و[todz.app/llms-full.txt](https://todz.app/llms-full.txt) يحويها كاملة.

ولتتيح للوكيل العمل على مهامك بدلًا من ذلك، راجع [ربط وكيل](/ar/connect-an-agent).
