title: أدوات MCP
description: الأدوات والـ prompt التي يحصل عليها الوكيل من خادم todz MCP، والنطاق الذي تحتاج إليه كل منها.
---

يتصل عميل MCP بخادم todz عبر OAuth فقط: أضف الرابط إلى عميلك وسجّل الدخول، كما يوضح [ربط وكيل](/ar/connect-an-agent). المنحة التي توافق عليها تحدد مجموعة الأدوات: نطاق المشروع يمنح أدوات المهام لمشروع واحد، ونطاق المالك يمنح أدوات الحساب وأدوات المهام نفسها لكل مشروع في الحساب. كل أداة أدناه تسمّي النطاق الذي تحتاج إليه.

- **نطاق المشروع** يحمل قائمة مهام مشروع واحد: المشروع الذي اخترته في شاشة الموافقة. ويستطيع أيضًا سرد المهام ونقلها داخل مساحة عمل ذلك المشروع. ولا ينشئ مساحة عمل أو مشروعًا ولا يعيد تسميتهما ولا يحذفهما أبدًا. معرّفات المهام تبدو هكذا `T-12`.
- **نطاق المالك** يحمل الحساب كله: مساحات عمله ومشاريعه وكل مهمة، فاتصال واحد يكشف كل ما يستطيع التطبيق فعله. لا يكون محددًا مسبقًا أبدًا في شاشة الموافقة، وتفصله من **الإعدادات** › **التطبيقات المتصلة**. ولا يصل إلى أي حساب آخر.
- **التحديد** يحمل مساحات العمل والمشاريع التي حدّدتها، وكل مشروع في مساحة عمل محددة، الجديدة منها أيضًا. يحصل على أدوات المهام وأداة مساحات العمل، التي لا تسرد إلا ما يشمله، ولا يحصل على أي من الأدوات التي تنشئ مساحة عمل أو مشروعًا أو تعيد تسميتهما أو تحذفهما أو تغيّر الإعدادات. ويمكنك تضييق التحديد من **الإعدادات** › **التطبيقات المتصلة**.

في نطاق المالك وفي التحديد، تأخذ كل أداة مهام وسيط `project` إلزاميًا: معرّف المشروع الذي تعمل عليه، من `workspaces`. لا يوجد مشروع افتراضي. مشروع حساب آخر، أو مشروع خارج التحديد، يجيب تمامًا كما يجيب مشروع غير موجود، ويحتاج النقل إلى أن يكون المشروعان داخل التحديد وفي مساحة عمل واحدة. ونطاق المشروع لا وسيط `project` فيه، إلا أن `move` يأخذ الوجهة هناك.

كل حذف يطلب وسيط `confirm` يحوي الاسم الحالي (العنوان الحالي للمهمة)؛ وعندما يختلف، لا يُحذف شيء.

## next

**النطاق:** نطاق المشروع ونطاق المالك.

المهمة المفتوحة الواحدة التي يُعمل عليها الآن في هذا المشروع، مع ملاحظاتها.

| الوسيط    | النوع  | الوصف                                                            |
| --------- | ------ | ---------------------------------------------------------------- |
| `project` | نص     | نطاق المالك فقط: معرّف المشروع الذي تعمل عليه أداة المهام، من workspaces. |

## add

**النطاق:** نطاق المشروع ونطاق المالك.

أضف مهمة أو أكثر. أعطِ كلًّا منها idempotency_key ليكون إعادة المحاولة آمنة.

| الوسيط            | النوع          | الوصف                                                                        |
| ----------------- | -------------- | ---------------------------------------------------------------------------- |
| `project`         | نص             | نطاق المالك فقط: معرّف المشروع الذي تعمل عليه أداة المهام، من workspaces.    |
| `tasks`           | قائمة          | المهام المراد إضافتها، كائن لكل مهمة.                                        |
| `title`           | نص             | عنوان قصير.                                                                  |
| `notes`           | نص أو null     | ملاحظات بصيغة Markdown.                                                      |
| `due_date`        | نص أو null     | تاريخ تقويمي، YYYY-MM-DD.                                                    |
| `idempotency_key` | نص أو null     | أي سلسلة فريدة لهذه المهمة؛ وتكرارها يعيد المهمة المضافة سابقًا.             |

## list

**النطاق:** نطاق المشروع ونطاق المالك.

اسرد المهام حسب الحالة ونافذة الاستحقاق والنص، بالترتيب اليدوي (المنجزة: الأحدث أولًا).

| الوسيط    | النوع           | الوصف                                                                                  |
| --------- | --------------- | -------------------------------------------------------------------------------------- |
| `project` | نص              | نطاق المالك فقط: معرّف المشروع الذي تعمل عليه أداة المهام، من workspaces.              |
| `state`   | نص              | `open` أو `done`. الافتراضي `open`.                                                    |
| `due`     | قائمة نصوص      | نوافذ الاستحقاق المراد تضمينها: `overdue` أو `today` أو `upcoming` أو `undated`. الفارغة تعني الكل. |
| `text`    | نص أو null      | نص يُبحث عنه في العناوين والملاحظات.                                                   |
| `limit`   | عدد صحيح        | كم مهمة تُعرض.                                                                         |

## update

**النطاق:** نطاق المشروع ونطاق المالك.

غيّر عنوان مهمة أو ملاحظاتها أو تاريخ استحقاقها أو مكانها في الترتيب. null يمسح الملاحظات أو تاريخ الاستحقاق.

| الوسيط      | النوع          | الوصف                                                                      |
| ----------- | -------------- | -------------------------------------------------------------------------- |
| `project`   | نص             | نطاق المالك فقط: معرّف المشروع الذي تعمل عليه أداة المهام، من workspaces.  |
| `id`        | نص             | معرّف المهمة، مثل `T-12`.                                                  |
| `title`     | نص             | عنوان قصير.                                                                |
| `notes`     | نص أو null     | ملاحظات بصيغة Markdown.                                                    |
| `due_date`  | نص أو null     | تاريخ تقويمي، YYYY-MM-DD.                                                  |
| `placement` | كائن           | أين تُنقل المهمة: `first` أو `last` أو `before` أو `after` نقطة ارتكاز.    |
| `kind`      | نص             | داخل `placement`: `first` أو `last` أو `before` أو `after`.                |
| `anchor`    | نص             | داخل `placement`، مع `before` و`after`: معرّف المهمة الأخرى.               |

## delete

**النطاق:** نطاق المشروع ونطاق المالك.

احذف مهمة نهائيًا. أعطِ عنوانها الحالي في <bdi>confirm</bdi>؛ ولا يُحذف شيء عندما يختلف. المهمة التي تقصد الإبقاء عليها في مكان آخر تحتاج إلى move. يعرض Mac المالك الحذف بعد تحديثه التالي.

| الوسيط    | النوع  | الوصف                                                                             |
| --------- | ------ | --------------------------------------------------------------------------------- |
| `project` | نص     | نطاق المالك فقط: معرّف المشروع الذي تعمل عليه أداة المهام، من workspaces.         |
| `id`      | نص     | معرّف المهمة، مثل `T-12`.                                                         |
| `confirm` | نص     | العنوان الحالي للمهمة، مكتوبًا كما هو تمامًا. لا يُحذف شيء عندما يختلف.           |

## move

**النطاق:** نطاق المشروع ونطاق المالك.

انقل مهمة إلى مشروع آخر في مساحة العمل نفسها. تحصل المهمة على معرّف جديد هناك. اعثر على معرّفات المشاريع بـ projects. يعرض Mac المالك النقل بعد تحديثه التالي.

| الوسيط        | النوع  | الوصف                                                                                               |
| ------------- | ------ | --------------------------------------------------------------------------------------------------- |
| `id`          | نص     | معرّف المهمة، مثل `T-12`.                                                                           |
| `project`     | نص     | نطاق المشروع: معرّف المشروع الذي تُنقل المهمة إليه، من أداة projects. نطاق المالك: معرّف المشروع الذي فيه المهمة، من workspaces. |
| `destination` | نص     | نطاق المالك فقط: معرّف المشروع الذي تُنقل المهمة إليه، من workspaces.                               |

## projects

**النطاق:** نطاق المشروع.

اسرد مشاريع مساحة العمل التي ينتمي إليها هذا الاتصال، مع معرّفاتها.

## workspaces

**النطاق:** نطاق المالك.

اسرد مساحات عمل هذا الحساب مع مشاريعها ومعرّفاتها.

لا تأخذ أي وسائط.

| ------ | ------ | ----------------------------------- |

## rename_workspace

| الوسيط      | النوع  | الوصف                                                                                |
| ----------- | ------ | ------------------------------------------------------------------------------------ |
| `workspace` | نص     | معرّف مساحة العمل، من workspaces.                                                    |
| `confirm`   | نص     | الاسم الحالي لمساحة العمل، مكتوبًا كما هو تمامًا. لا يُحذف شيء عندما يختلف.          |

## settings

**النطاق:** نطاق المالك.

اعرض إعدادات الحساب: المنطقة الزمنية وتنبيه الوكيل وبريد اليوم.

لا تأخذ أي وسائط.

## update_settings

**النطاق:** نطاق المالك.

غيّر إعدادات الحساب. أعطِ فقط ما يتغير.

| الوسيط              | النوع           | الوصف                                                                                    |
| ------------------- | --------------- | ---------------------------------------------------------------------------------------- |
| `time_zone`         | نص              | اسم المنطقة الزمنية، مثل America/Sao_Paulo.                                              |
| `agent_nudge`       | true أو false   | هل يضيف next سطرًا عن المهام المستحقة اليوم.                                             |
| `day_email`         | true أو false   | هل يُرسل بريد اليوم.                                                                     |
| `day_email_minutes` | عدد صحيح        | الدقائق بعد منتصف الليل، بمنطقتك الزمنية، التي يُرسل عندها بريد اليوم: من 0 إلى 1439.    |

## Prompts

يقدّم الخادم prompt واحدًا، `next`: ابدأ العمل على المهمة التالية في هذا المشروع.
