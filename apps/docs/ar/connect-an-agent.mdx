---
title: ربط وكيل
description: سجّل دخول Claude Code أو Claude.ai أو Codex إلى todz باستخدام OAuth. أُزيلت مفاتيح API.
---

خادم todz MCP على `https://api.todz.app/mcp` يسجّل دخول العملاء عبر MCP OAuth. أضف الرابط إلى عميلك. أول استدعاء يفتح متصفحك، وهناك توافق على التطبيق. OAuth هو الطريقة الوحيدة للاتصال.

إذا كنت تشغّل خادمك الخاص، فاستخدم رابطه بدل `https://api.todz.app/mcp`.

## تغيير جذري: أُزيلت مفاتيح API

في 2026-11-27 أزال todz مفاتيح API. توقفت مفاتيح المشاريع ومفاتيح المالك عن العمل، وحذف الخادم كل مفتاح مخزَّن. العميل الذي ما زال يرسل مفتاحًا يتلقى `401` مع إشارة إلى هذه الصفحة.

لإعادة ربط وكيل كان يستخدم مفتاحًا، شغّل `claude mcp add --transport http todz https://api.todz.app/mcp` وسجّل الدخول، كما يلي. احذف ترويسة `Authorization` القديمة، والمتغير `TODZ_API_KEY` إن كنت قد ضبطته. شاشة **ربط وكيل** في تطبيق Mac اختفت في التحديث نفسه.

## سجّل الدخول باستخدام OAuth

1. أدخل بريدك الإلكتروني في todz واجتز الفحص.
2. افتح رابط تسجيل الدخول من الرسالة **في المتصفح نفسه**.
3. اقرأ شاشة الموافقة: تذكر التطبيق والمكان الذي تعيدك إليه.
4. اختر مشروعًا واحدًا. الأول محدد مسبقًا. أو اختر **حسابك كله (نطاق المالك)**، وهو لا يكون محددًا مسبقًا أبدًا، ويحذّر بعبارة "يمكنه قراءة كل مهمة وتغييرها، وإنشاء كل مساحة عمل ومشروع وإعادة تسميته وحذفه."
5. وافق، أو ارفض.

نطاق المشروع يمنح أدوات المهام، والمشاريع الأخرى في مساحة عمله لأجل `move` و`projects`. ونطاق المالك يمنح أدوات الحساب وأدوات المهام نفسها لكل مشروع في الحساب، وتأخذ كل أداة معرّف `project` من `workspaces`. يذكر سجل المهمة التطبيق بالاسم الذي سجّله. راجع [أدوات MCP](/ar/mcp-tools).

تدوم رموز الوصول ساعة واحدة وتتجدد بنفسها. وتدوم رموز التحديث 30 يومًا وتتبدل عند كل استخدام؛ محاولة واحدة أخرى خلال 5 ثوانٍ تحصل على زوج جديد، ورمز مستهلك يُستخدم مرة أخرى لاحقًا يفصل التطبيق. يخزّن todz الرموز على هيئة digest فقط. يسري الاستخدام العادل وحد السحابة على كل تطبيق متصل.

لفصل تطبيق، افتح **الإعدادات** › **التطبيقات المتصلة** في تطبيق Mac. يتوقف التطبيق فورًا.

يجب أن تكون عناوين إعادة التوجيه `https` أو عنوان loopback (`127.0.0.1` أو `localhost` أو `[::1]`). تُرفض المخططات المخصصة، كما تشترط المواصفة.

### Claude Code

```bash
claude mcp add --transport http todz https://api.todz.app/mcp
```

ثم شغّل `/mcp` في Claude Code واختر todz لتسجيل الدخول. يفتح Claude Code المتصفح.

### Claude.ai وClaude Desktop

افتح **الإعدادات** › **الموصّلات** › **إضافة موصّل مخصص**، وأدخل `https://api.todz.app/mcp` رابطًا، ثم اضغط **اتصال**.

### Codex

أضف هذا إلى `~/.codex/config.toml`:

```toml
[mcp_servers.todz]
url = "https://api.todz.app/mcp"
```

ثم سجّل الدخول:

```bash
codex mcp login todz
```

### Cursor

يسجّل Cursor الدخول إلى خوادم MCP بعنوان `cursor://`، وهو ما لا تسمح به مواصفة MCP ويرفضه todz. لا يستطيع Cursor الاتصال بـ todz إلى أن يسجّل الدخول بعنوان `https` أو loopback.
