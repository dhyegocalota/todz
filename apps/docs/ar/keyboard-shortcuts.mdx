---
title: اختصارات لوحة المفاتيح
description: مفاتيح القوائم ومساحات العمل.
---

| المفاتيح | الإجراء |
| --- | --- |
| ⌘N | **مهمة جديدة** |
| ⇧⌘N | **مشروع جديد…** |
| ⌘R | **تحديث** |
| ⌥⌘I | **إظهار المفتّش** و**إخفاء المفتّش** |
| ⌘⌫ | **حذف المهمة…** للمهمة المحددة، في قائمة المهام؛ ويسأل أولًا |
| ⌘K | **التبديل إلى مساحة عمل…**، ويطلب Touch ID عندما يكون القفل مفعّلًا |
| ⌘1 … ⌘9 | التبديل بين مساحات العمل في النافذة المنبثقة وفي قائمة مساحات العمل |
| ⌃1 … ⌃9 | الانتقال إلى مساحة العمل 1 … 9، بينما todz في المقدمة |
| ⌃⌘[ | **مساحة العمل السابقة**، بينما todz في المقدمة |
| ⌃⌘] | **مساحة العمل التالية**، بينما todz في المقدمة |
| ⌃⌥⌘1 … ⌃⌥⌘9 | الانتقال إلى مساحة العمل 1 … 9، من أي تطبيق، عندما يكون **التبديل من أي تطبيق** مفعّلًا (معطّل افتراضيًا) |

في النافذة المنبثقة لشريط القوائم:

| المفاتيح | الإجراء |
| --- | --- |
| ⌘O | فتح todz |
| ⌘N | التركيز على **أضف مهمة** |
| ↓ و↑ | التنقل بين البطاقة والصفوف و**المنجزة اليوم** |
| المسافة | تعليم المهمة منجزة، أو فتحها من جديد |
| Return | عرض المهمة في نافذة todz |
| ⌘↩ | تعليم مهمة **التالية** منجزة، من **أضف مهمة** |
| ⌘⌫ | **حذف المهمة…** للصف المحدد؛ ويسأل أولًا |

يمكن إعادة تعيين مفاتيح مساحات العمل العامة تحت **اختصارات مساحات العمل** في todz › الإعدادات. تشرح [مساحات العمل](/ar/workspaces) كيف، وماذا تفعل حين يحتل تطبيق آخر المفاتيح.
