title: مقدمة
description: قائمة مهام تتشاركها مع وكلاء الذكاء الاصطناعي.
---

todz قائمة مهام يتشاركها وكلاء الذكاء الاصطناعي ومالكهم. وهو يضع MCP أولًا: كل ما تفعله في التطبيق يستطيع الوكيل فعله عبر خادم <bdi>MCP</bdi>، من Claude Code أو Codex أو Cursor أو أي عميل MCP آخر.

يحتفظ تطبيق Mac الأصلي بمهامك في النافذة الرئيسية وفي شريط القوائم وفي ويدجت على سطح المكتب، وكل تغيير يجريه وكيل يظهر هناك مع اسم العميل الذي أجراه. كل مساحة عمل معزولة، ومشاريع مساحة العمل تُبقي مهامها منفصلة. مع [خصوصية مساحات العمل](/ar/workspace-privacy) تختفي مساحات عملك الأخرى من Mac إلى أن يعيدها Touch ID أو كلمة مرورك.
