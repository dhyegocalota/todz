---
title: Usa estas docs desde tu agente
description: Da estas docs a un agente mediante MCP o un archivo de texto plano.
---

Estas docs tienen su propio servidor MCP. En Claude Code:

```bash
claude mcp add --transport http todz-docs https://docs.todz.app/mcp
```

Para un agente que lee texto plano, [todz.app/llms.txt](https://todz.app/llms.txt) lista las páginas y [todz.app/llms-full.txt](https://todz.app/llms-full.txt) las contiene completas.

Para que un agente trabaje tus tareas, consulta [Conectar un agente](/es/connect-an-agent).
