---
title: Privacy
description: What todz counts, what it never keeps, and how to turn it off.
---

todz counts how the product is used so it can be improved. It counts; it never records what you do or what you write.

## What is counted

- **On the server:** daily totals, such as active owners, new sign-ins, workspaces, tasks added and done, and MCP calls by client name.
- **On todz.app:** page views, download clicks and star clicks, counted by the server that serves the page. There is no third-party script.
- **Updates:** update checks per app version and per macOS major version, rolled up per day.
- **In the app, only if you opt in:** at most one rollup a day with a count per feature, such as the popover opened, the day close, the morning glance, a shortcut used and several workspaces shown.

## What is never stored

- Task titles, notes, project or workspace names, or any task content.
- Email addresses, IP addresses or user agents.
- A log of single events. Only daily totals are kept.
- An identifier that outlives 30 days.

## The opt-in

Sharing usage from the app is off by default. todz asks once; you can change your answer in todz › Settings.

The rollup holds counts only, is at most 1 KB per install per day, and carries a random install identifier that rotates every 30 days. The identifier is never stored on the server.

## Retention

The server keeps daily rollups only, for 13 months, and then deletes them.

## Self-host

A server you run has all of this off. Nothing reaches todz from it unless you turn it on.
