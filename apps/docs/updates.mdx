---
title: Updates
description: How the Mac app updates itself and how to turn that off.
---

The app updates itself. By default it checks once a day through Sparkle, downloads a new version in the background and installs it when you quit or reopen todz. Turn this off with **Update todz automatically** in todz › Settings; you can still choose **Check for Updates…** in the todz menu at any time. Sparkle verifies each update against a key inside the app before it installs.

The official app updates from todz.app's signed appcast whatever server it points at: the server you choose and the app's updates are independent. To check a download by hand instead, see [Install on Mac](/install-on-mac#2-verify-the-download).
