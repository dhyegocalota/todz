todz est open source sous licence [AGPL-3.0](https://github.com/dhyegocalota/todz/blob/main/LICENSE). Tout le dépôt est sous une seule licence : l’app, le serveur, les bibliothèques et ces docs.

Le code est sur [github.com/dhyegocalota/todz](https://github.com/dhyegocalota/todz). Si todz vous est utile, choisissez **Mettre une étoile à todz sur GitHub** dans le panneau ou dans le menu todz. **Open source sur GitHub** dans todz › Réglages ouvre aussi le dépôt.

## Contribuer

Lisez d’abord [CONTRIBUTING](https://github.com/dhyegocalota/todz/blob/main/.github/CONTRIBUTING.md). Les contributions sont soumises au [Contributor License Agreement](https://github.com/dhyegocalota/todz/blob/main/.github/CLA.md). Signalez un problème de sécurité comme l’indique la [politique de sécurité](https://github.com/dhyegocalota/todz/blob/main/.github/SECURITY.md), jamais dans un ticket public.

Pour faire tourner votre propre serveur, voir [Auto-hébergement](/fr/self-host).
