## 1. Obtenir l’app

Téléchargez todz pour Mac depuis [todz.app/download](https://todz.app/download), puis [installez-le sur votre Mac](/fr/install-on-mac) : vérifiez le téléchargement et ouvrez-le une première fois avec **Ouvrir quand même**. Vous pouvez aussi le compiler depuis les sources, comme dans [l’étape de compilation du guide d’auto-hébergement](/fr/self-host#7-compiler-todz-pour-macos-et-le-pointer-vers-votre-serveur) ; une version compilée garde todz cloud comme serveur.

## 2. Se connecter

Saisissez votre e-mail, appuyez sur **Envoyer le lien** et ouvrez le lien du message sur le même Mac que celui qui l’a demandé.

<Note>
  Les places gratuites sur todz cloud sont extrêmement limitées. Si le cloud est complet, le message que vous recevez l’indique et vous explique comment rejoindre la file d’attente ; l’auto-hébergement reste toujours ouvert. Voir [Utilisation raisonnable](/fr/fair-use#places-sur-todz-cloud) et [Auto-hébergement](/fr/self-host).
</Note>

<Note>
  Vous utilisez votre propre serveur ? Changez-le sous **Serveur** dans les Réglages, ou depuis la ligne du serveur de l’écran de connexion. **Utiliser todz cloud** revient au serveur par défaut. Voir [Auto-hébergement](/fr/self-host).
</Note>

## 3. La suite

[Connectez un agent](/fr/connect-an-agent) à un projet, et il pourra travailler vos tâches. Activez la [confidentialité des espaces de travail](/fr/workspace-privacy) pour garder vos autres espaces de travail hors de vue.
