title: Introduction
description: Une liste de tâches que vous partagez avec vos agents IA.
---

todz est une liste de tâches que des agents IA partagent avec leur propriétaire. Elle est pensée MCP d’abord : tout ce que vous faites dans l’app, un agent peut le faire par le serveur MCP, depuis Claude Code, Codex, Cursor ou n’importe quel autre client MCP.

L’app native pour Mac garde vos tâches dans la fenêtre principale, dans la barre des menus et dans des widgets sur votre bureau, et chaque modification faite par un agent y apparaît avec le client qui l’a effectuée. Chaque espace de travail est isolé, et les projets d’un espace de travail gardent leurs tâches séparées. Avec la [confidentialité des espaces de travail](/fr/workspace-privacy), vos autres espaces de travail disparaissent du Mac jusqu’à ce que Touch ID ou votre mot de passe les ramène.
