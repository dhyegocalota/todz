---
title: Raccourcis clavier
description: Les touches des listes et des espaces de travail.
---

| Touches | Action |
| --- | --- |
| ⌘N | **Nouvelle tâche** |
| ⇧⌘N | **Nouveau projet…** |
| ⌘R | **Actualiser** |
| ⌥⌘I | **Afficher l’inspecteur** et **Masquer l’inspecteur** |
| ⌘K | **Changer d’espace de travail…**, qui demande Touch ID quand le verrouillage est activé |
| ⌘1 … ⌘9 | Changer d’espace de travail dans le panneau et dans le menu des espaces de travail |
| ⌃1 … ⌃9 | Aller à l’espace de travail 1 … 9, tant que todz est au premier plan |
| ⌃⌘[ | **Espace de travail précédent**, tant que todz est au premier plan |
| ⌃⌘] | **Espace de travail suivant**, tant que todz est au premier plan |
| ⌃⌥⌘1 … ⌃⌥⌘9 | Aller à l’espace de travail 1 … 9, depuis n’importe quelle app, quand **Changer depuis n’importe quelle app** est activé (désactivé par défaut) |

Dans le panneau de la barre des menus :

| Touches | Action |
| --- | --- |
| ⌘O | Ouvrir todz |
| ⌘N | Placer le curseur dans **Ajouter une tâche** |
| ↓ et ↑ | Se déplacer dans la carte, les lignes et **Terminées aujourd’hui** |
| Espace | Marquer la tâche comme terminée, ou la rouvrir |
| Retour | Afficher la tâche dans la fenêtre de todz |
| ⌘↩ | Marquer comme terminée la tâche **À suivre**, depuis **Ajouter une tâche** |

Les touches globales des espaces de travail sont reconfigurables sous **Raccourcis des espaces de travail** dans todz › Réglages. [Espaces de travail](/fr/workspaces) explique comment, et quoi faire quand une autre app détient une combinaison.
