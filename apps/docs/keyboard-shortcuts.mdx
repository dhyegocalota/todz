---
title: Keyboard shortcuts
description: The keys of the lists and of the workspaces.
---

| Keys | Action |
| --- | --- |
| ⌘N | **New Task** |
| ⇧⌘N | **New Project…** |
| ⌘R | **Refresh** |
| ⌥⌘I | **Show Inspector** and **Hide Inspector** |
| ⌘1 … ⌘9 | Switch workspace in the popover and in the workspace menu |
| ⌃1 … ⌃9 | Go to workspace 1 … 9, while todz is in front |
| ⌃⌘[ | **Previous Workspace**, while todz is in front |
| ⌃⌘] | **Next Workspace**, while todz is in front |
| ⌃⌥⌘1 … ⌃⌥⌘9 | Go to workspace 1 … 9, from any app, when **Switch from any app** is on (off by default) |

The global workspace keys are rebindable under **Workspace shortcuts** in todz › Settings. [Workspaces](/workspaces) says how, and what to do when another app holds a chord.
