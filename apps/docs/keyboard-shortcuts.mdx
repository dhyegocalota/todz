---
title: Keyboard shortcuts
description: The keys of the lists and of the workspaces.
---

| Keys | Action |
| --- | --- |
| ⌘N | **New Task** |
| ⇧⌘N | **New Project…** |
| ⌘R | **Refresh** |
| ⌥⌘I | **Show Inspector** and **Hide Inspector** |
| ⌘1 … ⌘9 | Switch workspace in the popover and in the workspace menu |
| ⌃1 … ⌃9 | Go to workspace 1 … 9, from any app |
| ⌃⌘[ | **Previous Workspace** |
| ⌃⌘] | **Next Workspace** |

Every workspace key is rebindable under **Workspace shortcuts** in todz › Settings. [Workspaces](/workspaces) says how, and what to do when Mission Control holds ⌃1–⌃9.
