---
title: MCP 工具
description: 智能体从 todz MCP 服务器获得的工具和提示词，以及每个工具所需的范围。
---

MCP 客户端只通过 OAuth 连接 todz 服务器：把 URL 添加到你的客户端并登录，方法见[连接智能体](/zh/connect-an-agent)。你批准的授权决定可用的工具集：项目范围可使用一个项目的任务工具，所有者范围可使用账户工具，以及针对账户中每个项目的同一组任务工具。下面的每个工具都写明了它所需的范围。

- **项目范围**掌管一个项目的待办清单：即你在授权界面上选择的那个项目。它也可以列出并移动该项目所在工作区内的任务。它从不创建、重命名或删除工作区或项目。任务 id 形如 `T-12`。
- **所有者范围**掌管整个账户：它的工作区、它的项目和每一个任务，所以一个连接就暴露了 App 能做的一切。它在授权界面上从不预先选中，你可以在**设置** › **已连接的应用**中断开它。它无法触及任何其他账户。

在所有者范围下，每个任务工具都需要一个 `project` 参数：它要操作的项目的 id，取自 `workspaces`。没有默认项目。其他账户的项目，其响应与不存在的项目完全一样。项目范围没有 `project` 参数，只有 `move` 在这里用它来指定目的地。

每次删除都要求一个 `confirm` 参数，内容为当前的名称（任务则为当前的标题）；两者不一致时，什么都不会被删除。

## next

**范围：**项目范围和所有者范围。

此项目中现在要做的那一个未完成任务，连同它的备注。

| 参数      | 类型   | 说明                                                             |
| --------- | ------ | ---------------------------------------------------------------- |
| `project` | 文本   | 仅限所有者范围：任务工具所操作的项目的 id，取自 workspaces。 |

## add

**范围：**项目范围和所有者范围。

添加一个或多个任务。给每个任务一个 idempotency_key，重试时就是安全的。

| 参数              | 类型           | 说明                                                                         |
| ----------------- | -------------- | ---------------------------------------------------------------------------- |
| `project`         | 文本           | 仅限所有者范围：任务工具所操作的项目的 id，取自 workspaces。                 |
| `tasks`           | 列表           | 要添加的任务，每个一个对象。                                                 |
| `title`           | 文本           | 简短的标题。                                                                 |
| `notes`           | 文本或 null    | Markdown 备注。                                                              |
| `due_date`        | 文本或 null    | 日历日期，YYYY-MM-DD。                                                       |
| `idempotency_key` | 文本或 null    | 对该任务唯一的任意字符串；重复使用它会返回已添加的那个任务。                 |

## list

**范围：**项目范围和所有者范围。

按状态、到期时间范围和文本列出任务，按手动顺序排列（已完成的：最新的在前）。

| 参数      | 类型            | 说明                                                                                   |
| --------- | --------------- | -------------------------------------------------------------------------------------- |
| `project` | 文本            | 仅限所有者范围：任务工具所操作的项目的 id，取自 workspaces。                           |
| `state`   | 文本            | `open` 或 `done`。默认为 `open`。                                                      |
| `due`     | 文本列表        | 要包含的到期时间范围：`overdue`、`today`、`upcoming` 或 `undated`。留空表示全部。      |
| `text`    | 文本或 null     | 要在标题和备注中查找的文本。                                                           |
| `limit`   | 整数            | 显示多少个任务。                                                                       |

## show

**范围：**项目范围和所有者范围。

显示一个任务及其状态、到期日期和备注。

| 参数      | 类型   | 说明                                                                         |
| --------- | ------ | ---------------------------------------------------------------------------- |
| `project` | 文本   | 仅限所有者范围：任务工具所操作的项目的 id，取自 workspaces。                 |
| `id`      | 文本   | 任务 id，形如 `T-12`。                                                       |

## history

**范围：**项目范围和所有者范围。

按从旧到新的顺序显示一个任务发生过什么：谁在何时做了什么。

| 参数      | 类型   | 说明                                                                         |
| --------- | ------ | ---------------------------------------------------------------------------- |
| `project` | 文本   | 仅限所有者范围：任务工具所操作的项目的 id，取自 workspaces。                 |
| `id`      | 文本   | 任务 id，形如 `T-12`。                                                       |

## update

**范围：**项目范围和所有者范围。

更改任务的标题、备注、到期日期或在顺序中的位置。null 会清除备注或到期日期。

| 参数        | 类型           | 说明                                                                       |
| ----------- | -------------- | -------------------------------------------------------------------------- |
| `project`   | 文本           | 仅限所有者范围：任务工具所操作的项目的 id，取自 workspaces。               |
| `id`        | 文本           | 任务 id，形如 `T-12`。                                                     |
| `title`     | 文本           | 简短的标题。                                                               |
| `notes`     | 文本或 null    | Markdown 备注。                                                            |
| `due_date`  | 文本或 null    | 日历日期，YYYY-MM-DD。                                                     |
| `placement` | 对象           | 把任务移到哪里：`first`、`last`，或某个锚点之前（`before`）或之后（`after`）。 |
| `kind`      | 文本           | 位于 `placement` 内：`first`、`last`、`before` 或 `after`。                |
| `anchor`    | 文本           | 位于 `placement` 内，配合 `before` 和 `after`：另一个任务的 id。           |

## done

**范围：**项目范围和所有者范围。

完成一个或多个任务，可附带一条说明做了什么的备注。

| 参数      | 类型           | 说明                                                                         |
| --------- | -------------- | ---------------------------------------------------------------------------- |
| `project` | 文本           | 仅限所有者范围：任务工具所操作的项目的 id，取自 workspaces。                 |
| `ids`     | 文本列表       | 任务 id，形如 `T-12`。                                                       |
| `note`    | 文本或 null    | 做了什么。                                                                   |

## reopen

**范围：**项目范围和所有者范围。

重新打开一个或多个已完成的任务。

| 参数      | 类型           | 说明                                                                         |
| --------- | -------------- | ---------------------------------------------------------------------------- |
| `project` | 文本           | 仅限所有者范围：任务工具所操作的项目的 id，取自 workspaces。                 |
| `ids`     | 文本列表       | 任务 id，形如 `T-12`。                                                       |

## delete

**范围：**项目范围和所有者范围。

永久删除一个任务。把它当前的标题作为 confirm 传入；两者不一致时，什么都不会被删除。想保留在别处的任务需要用 move。所有者的 Mac 会在下一次更新后显示这次删除。

| 参数      | 类型   | 说明                                                                              |
| --------- | ------ | --------------------------------------------------------------------------------- |
| `project` | 文本   | 仅限所有者范围：任务工具所操作的项目的 id，取自 workspaces。                      |
| `id`      | 文本   | 任务 id，形如 `T-12`。                                                            |
| `confirm` | 文本   | 任务当前的标题，必须一字不差地键入。两者不一致时，什么都不会被删除。              |

## move

**范围：**项目范围和所有者范围。

把任务移到同一工作区的另一个项目。任务在那里会得到一个新的 id。用 projects 查找项目 id。所有者的 Mac 会在下一次更新后显示这次移动。

| 参数          | 类型   | 说明                                                                                                |
| ------------- | ------ | --------------------------------------------------------------------------------------------------- |
| `id`          | 文本   | 任务 id，形如 `T-12`。                                                                              |
| `project`     | 文本   | 项目范围：任务要移往的项目的 id，取自 projects 工具。所有者范围：任务当前所在项目的 id，取自 workspaces。 |
| `destination` | 文本   | 仅限所有者范围：任务要移往的项目的 id，取自 workspaces。                                            |

## projects

**范围：**项目范围。

列出此连接所属工作区的各个项目及其 id。

它不需要参数。

## workspaces

**范围：**所有者范围。

列出此账户的各个工作区，以及它们的项目和 id。

它不需要参数。

## create_workspace

**范围：**所有者范围。

创建一个工作区。它起初有一个收件箱项目。

| 参数     | 类型   | 说明                                |
| -------- | ------ | ----------------------------------- |
| `name`   | 文本   | 名称，最多 80 个字符。              |

## rename_workspace

**范围：**所有者范围。

重命名一个工作区。

| 参数        | 类型   | 说明                                  |
| ----------- | ------ | ------------------------------------- |
| `workspace` | 文本   | 工作区的 id，取自 workspaces。        |
| `name`      | 文本   | 名称，最多 80 个字符。                |

## delete_workspace

**范围：**所有者范围。

永久删除一个工作区及其所有项目和任务。把它当前的名称作为 confirm 传入；两者不一致时，什么都不会被删除。

| 参数        | 类型   | 说明                                                                                 |
| ----------- | ------ | ------------------------------------------------------------------------------------ |
| `workspace` | 文本   | 工作区的 id，取自 workspaces。                                                       |
| `confirm`   | 文本   | 工作区当前的名称，必须一字不差地键入。两者不一致时，什么都不会被删除。               |

## create_project

**范围：**所有者范围。

在工作区中创建一个项目。

| 参数        | 类型   | 说明                                  |
| ----------- | ------ | ------------------------------------- |
| `workspace` | 文本   | 工作区的 id，取自 workspaces。        |
| `name`      | 文本   | 名称，最多 80 个字符。                |

## rename_project

**范围：**所有者范围。

重命名一个项目。收件箱无法重命名。

| 参数      | 类型   | 说明                                |
| --------- | ------ | ----------------------------------- |
| `project` | 文本   | 项目的 id，取自 workspaces。        |
| `name`    | 文本   | 名称，最多 80 个字符。              |

## delete_project

**范围：**所有者范围。

永久删除一个项目及其任务。把它当前的名称作为 confirm 传入；两者不一致时，什么都不会被删除。收件箱无法删除。

| 参数      | 类型   | 说明                                                                                |
| --------- | ------ | ----------------------------------------------------------------------------------- |
| `project` | 文本   | 项目的 id，取自 workspaces。                                                        |
| `confirm` | 文本   | 项目当前的名称，必须一字不差地键入。两者不一致时，什么都不会被删除。                |

## settings

**范围：**所有者范围。

显示账户设置：时区、智能体提醒和每日邮件。

它不需要参数。

## update_settings

**范围：**所有者范围。

更改账户设置。只需给出要更改的内容。

| 参数                | 类型            | 说明                                                                                     |
| ------------------- | --------------- | ---------------------------------------------------------------------------------------- |
| `time_zone`         | 文本            | 时区名称，例如 America/Sao_Paulo。                                                       |
| `agent_nudge`       | true 或 false   | next 是否附加一行关于今天到期任务的内容。                                                |
| `day_email`         | true 或 false   | 是否发送每日邮件。                                                                       |
| `day_email_minutes` | 整数            | 每日邮件在你所在时区午夜之后多少分钟发送：0 到 1439。                                    |

## 提示词

服务器提供一个提示词 `next`：开始处理此项目的下一个任务。
