title: 隐私
description: todz 具体统计什么、绝不存储什么，以及如何关闭。
---

todz 以每日总数的形式统计使用情况。它从不存储任何人的操作日志，也从不读取你的任务来做统计。

## 统计什么

每项统计都是某一天的一个数字，最多带一个简短的标签。

| 统计项 | 来源 | 标签 |
| --- | --- | --- |
| 所有者、工作区、项目 | 服务器自己的记录，每晚一次 | 无 |
| 已添加的任务、已完成的任务 | 来自每个项目的计数，每晚一次 | 无 |
| 智能体写入 | 对智能体所做更改的计数，每晚一次 | 智能体的名称，取自固定列表（Claude Code、Codex、Cursor、Gemini、Windsurf、Zed、VS Code），其他一律记为 `other` |
| 已发送的每日邮件 | 服务器自己的记录，每晚一次 | 无 |
| 更新检查 | Mac App 请求更新 | App 版本和 macOS 主版本，例如 `0.2.1\|15` |
| 共享的使用报告 | Mac App，仅当你开启**共享匿名使用数据**时 | App 版本和 macOS 主版本 |
| 共享的使用事件 | 同一份报告 | `popover_opened`、`day_closed`、`morning_glance`、`shortcut_used`、`multi_workspace` 之一 |

## 绝不存储什么

- 不存任何任务标题、备注、项目名称、工作区名称或邮箱地址。
- 不存 IP 地址，也不存 user agent。更新检查的 user agent 只用来读取两个版本号，随后即丢弃。
- 不存事件日志，也不存任何单个事件的时间戳。只有日期和总数。
- Mac App 随报告发送的随机代码每 30 天更换一次，只用来减缓滥用，而且从不存储。

总数保存 13 个月，之后由服务器删除。

## 共享匿名使用数据

Mac App 只会询问一次。在你说“是”之前它都是关闭的，你随时可以在设置中更改。开启后，App 会在你的 Mac 上记录上面五种事件的计数，并每天发送一份很小的报告：计数、App 版本、macOS 主版本和随机代码。报告不到 1 KB，服务器会拒绝任何超过 2 KB 的内容。

## 自行托管

你运行的服务器什么都不统计。设置项 `TELEMETRY` 除非恰好设为 `on`，否则就是关闭的，而自行托管指南会让你把它删掉。登录到你的服务器的 Mac App 会把报告发给你的服务器，而你的服务器会拒绝它。

## 数字在哪里查看

只有托管服务的所有者能读取这些数字，查看的地方是一个需要登录的管理页面，并可导出 CSV。代码是开源的：参见仓库里的 `apps/api/src/telemetry`。
