todz 以 [AGPL-3.0](https://github.com/dhyegocalota/todz/blob/main/LICENSE) 许可证开源。整个仓库只有一个许可证：App、服务器、各个库，以及这些文档。

代码在 [github.com/dhyegocalota/todz](https://github.com/dhyegocalota/todz)。如果 todz 对你有用，请在弹出窗口或 todz 菜单中选择**在 GitHub 上为 todz 加星**。todz › 设置里的**GitHub 上的开源项目**也会打开这个仓库。

## 参与贡献

请先阅读 [CONTRIBUTING](https://github.com/dhyegocalota/todz/blob/main/.github/CONTRIBUTING.md)。贡献适用[贡献者许可协议](https://github.com/dhyegocalota/todz/blob/main/.github/CLA.md)。报告安全问题时，请按[安全政策](https://github.com/dhyegocalota/todz/blob/main/.github/SECURITY.md)的说明去做，千万不要发在公开的 issue 里。

要运行你自己的服务器，请参见[自行托管](/zh/self-host)。
