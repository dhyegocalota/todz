## 1. 获取 App

从 [todz.app/download](https://todz.app/download) 下载 todz for Mac，然后[把它安装到你的 Mac 上](/zh/install-on-mac)：验证下载的文件，并用**仍要打开**打开一次。你也可以从源代码构建，方法见[自行托管指南的构建步骤](/zh/self-host#7-构建-macos-应用并指向你的服务器)；自行构建的版本仍以 todz cloud 作为服务器。

## 2. 登录

输入你的邮箱，按下**发送链接**，然后在发出请求的同一台 Mac 上打开邮件里的链接。

<Note>
  免费的 todz cloud 名额极其有限。如果云端已满，你收到的邮件会这样告诉你，并说明如何排队；自行托管永远开放。参见[合理使用](/zh/fair-use#todz-cloud-容量)和[自行托管](/zh/self-host)。
</Note>

<Note>
  运行自己的服务器？在设置的**服务器**下更改，或从登录界面的服务器那一行更改。**使用 todz cloud** 会回到默认设置。参见[自行托管](/zh/self-host)。
</Note>

## 3. 接下来

[连接智能体](/zh/connect-an-agent)到某个项目，它就能处理你的任务。开启[工作区隐私](/zh/workspace-privacy)，让你的其他工作区不被看见。
