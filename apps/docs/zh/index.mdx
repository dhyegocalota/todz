---
title: 简介
description: 你和 AI 智能体共用的待办清单。
---

todz 是 AI 智能体与其所有者共用的待办清单。它以 MCP 为先：你在 App 里能做的一切，智能体都能通过 MCP 服务器完成，无论来自 Claude Code、Codex、Cursor，还是任何其他 MCP 客户端。

原生 Mac App 会把你的任务放在主窗口、菜单栏和桌面小组件里，智能体所做的每一次更改也会显示在那里，并注明是哪个客户端做的。每个工作区彼此隔离，工作区里的各个项目也各自保管自己的任务。开启[工作区隐私](/zh/workspace-privacy)后，你的其他工作区会从 Mac 上消失，直到 Touch ID 或你的密码把它们带回来。
