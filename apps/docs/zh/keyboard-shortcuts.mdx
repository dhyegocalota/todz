---
title: 键盘快捷键
description: 列表和工作区的快捷键。
---

| 按键 | 操作 |
| --- | --- |
| ⌘N | **新建任务** |
| ⇧⌘N | **新建项目…** |
| ⌘R | **刷新** |
| ⌥⌘I | **显示检查器**和**隐藏检查器** |
| ⌘K | **切换工作区…**，开启锁定时会要求 Touch ID |
| ⌘1 … ⌘9 | 在弹出窗口和工作区菜单中切换工作区 |
| ⌃1 … ⌃9 | 前往工作区 1 … 9，在 todz 位于最前时 |
| ⌃⌘[ | **上一个工作区**，在 todz 位于最前时 |
| ⌃⌘] | **下一个工作区**，在 todz 位于最前时 |
| ⌃⌥⌘1 … ⌃⌥⌘9 | 前往工作区 1 … 9，可在任何 App 中使用，需开启**从任何 App 切换**（默认关闭）|

在菜单栏弹出窗口中：

| 按键 | 操作 |
| --- | --- |
| ⌘O | 打开 todz |
| ⌘N | 聚焦**添加任务** |
| ↓ 和 ↑ | 在卡片、各行和**今天已完成**之间移动 |
| 空格键 | 把任务标为已完成，或重新打开 |
| Return | 在 todz 窗口中显示该任务 |
| ⌘↩ | 在**添加任务**中，把“下一项”任务标为已完成 |

全局工作区快捷键可以在 todz › 设置的**工作区快捷键**下重新绑定。[工作区](/zh/workspaces)说明了方法，以及别的 App 占用了某个组合键时该怎么办。
