---
title: 工作区隐私
description: 用 Touch ID 或 Mac 密码隐藏你的其他工作区，并了解它们在哪些地方不会被看到。
---

工作区隐私会让你的其他工作区在 Mac 上不被看见。开启后，锁定的会话只显示锁定时已选中的那些工作区，画面与只持有这些工作区的账户完全一样：没有任何其他工作区的占位符、数量、锁图标或名称。Touch ID 或你的 Mac 密码可以把其余的带回来。

## 开启

打开 todz › 设置 › 隐私与更新，开启**切换工作区需要 Touch ID**。它默认关闭，开启时不会要求任何验证。**再次询问的间隔**设定解锁后的会话持续多久：1、5、15 或 60 分钟。

## 其他工作区在哪些地方保持隐藏

会话处于锁定状态时，保持可见的那一组之外的每个工作区都不会出现在：

- 边栏、工作区切换器和工作区菜单。
- 菜单栏计数、丝带和弹出窗口。
- 小组件。会话锁定时，它们的缓存数据会被清除，所以小组件绝不会显示被隐藏的工作区。
- Siri 和快捷指令。
- `todz://` 链接，其响应就像该项目不存在一样。
- 设置及其**已连接的应用**。
- 晨间速览、收工总结和全局工作区快捷键。

## 把它们带回来

开启锁定且会话已解锁时，直接点按某个工作区会单独切换到它，⌘ 点按或**同时显示**会把它加入视图或移出视图，所以你可以显示一个、几个或全部。会话锁定时，你在那一刻选中的那一组会保持可见，即使其中有多个工作区；**所有工作区**会固定为它当时包含的那些工作区，所以你之后添加的工作区永远不会加入。启动时会打开上次选中的那一组，绝不会更多。

在那一组之内切换，或把某个工作区移出，从不询问。要触及它之外，就会要求 Touch ID 或你的 Mac 密码：选择**切换工作区…**（⌘K，菜单栏弹出窗口的 **…** 菜单中也有），或朝着那一组之外的工作区添加、切换，或选择**所有工作区**。如果你拒绝这个提示，什么都不会改变。创建或删除工作区、关闭这项设置以及更改时间，也都以同样的方式询问。锁定关闭时，工作区照常工作。

## 何时再次锁定

- Mac 进入睡眠或屏幕锁定时，以及屏幕保护程序启动时。
- 退出 todz 时：每次启动都处于锁定状态。
- 经过你在**再次询问的间隔**下选定的时间后。
- 选择**立即锁定**时，该选项只在会话处于解锁状态时才会显示。

## 它不保护什么

<Warning>
  工作区隐私是 Mac 上的一道隐私屏障，不是加密。任何知道你 Mac 密码的人都可以解锁它，而且它不会改变服务器：通过 OAuth 连接的智能体仍然可以访问它的项目。
</Warning>

要切换、同时显示多个、重命名和删除工作区，请参见[工作区](/zh/workspaces)。
