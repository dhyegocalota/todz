## 登录链接没有反应，或提示无法登录

请在发出请求的同一台 Mac 上打开邮件里的链接。在另一台 Mac 上打开的链接，或者你在申请了更新的链接之后再打开的旧链接，都会被拒绝，并提示“无法用该链接登录。请等一分钟，然后再从邮件中打开一次。”请按**发送链接**重新申请一个，并打开最新的那封邮件。

## 我的智能体无法用 OAuth 登录

请在你输入邮箱的同一个浏览器中打开邮件里的登录链接。如果客户端报告重定向错误，或需要自定义地址协议，todz 会拒绝它，所以该客户端暂时无法连接，参见[连接智能体](/zh/connect-an-agent)。

如果浏览器每次都提示“此链接无法用于连接 App”，说明客户端在重复使用服务器已不认识的注册信息。请清除客户端保存的登录信息后重新连接：在 Claude Code 中运行 `/mcp`，选择 todz，然后选择**清除认证**。

## 尝试次数过多

“尝试次数过多。请等一分钟，然后再试。”表示服务器限制了链接请求。请等一分钟，然后只按一次**发送链接**。

## macOS 不肯打开 App

todz 没有经过公证，所以 macOS 第一次会拒绝它。先打开一次 todz 并关闭警告，然后前往**系统设置** › **隐私与安全性**，点按**仍要打开**，并用密码或 Touch ID 确认。参见[在 Mac 上安装](/zh/install-on-mac#1-下载并打开)。

## 服务器较旧

App 中出现**服务器较旧**，意思是“此服务器比这个 App 期望的版本旧。运行它的人可以更新它。”如果是你自己的服务器，请部署当前版本；参见[自行托管](/zh/self-host)。

## 更新无法安装

如果 Sparkle 提示 todz 无法从它被下载到的位置更新，请把 `Todz.app` 拖进“应用程序”，从那里打开，然后再检查一次。参见[更新](/zh/updates)。
