每个版本都是 [github.com/dhyegocalota/todz/tags](https://github.com/dhyegocalota/todz/tags) 上名为 `mac-v<version>` 的 GitHub 标签。App 通过读取 [todz.app/download/appcast.xml](https://todz.app/download/appcast.xml) 来自行更新。

## 0.2.9

**todz 会说十种语言。**App、它的小组件、todz.app、邮件和这些文档，都有 English、Português (Brasil)、Español、Deutsch、Français、日本語、한국어、简体中文、العربية 和 हिन्दी 版本。App 会跟随你 Mac 的语言；设置 › 通用中的**语言**可以选择另一种，**外观**则有系统、浅色、深色。阿拉伯语从右向左阅读。

- **用验证码登录。**登录邮件中，链接旁边有一个六位数的验证码。在 App 中键入或粘贴它；两者任选其一即可登录，用掉其中一个，另一个也随之失效。
- **精确选择智能体能访问什么。**连接 App 时，可以选择整个账户，或工作区和项目的任意组合。设置中的**已连接的应用**会用平实的话说明每个 App 的访问范围，并可限制它或断开它。
- **删除任务。**在窗口和弹出窗口中，任务的上下文菜单、“任务”菜单和 ⌘⌫ 里都有**删除任务…**。它会先询问，并且默认选项是“取消”。
- **工作区，更清晰。**在工作区切换器中直接点按，会显示那个工作区；⌘ 点按或**同时显示**则会再加入一个。开启工作区锁后，锁定时已打开的那些工作区保持可见，触及其他任何工作区都会要求 Touch ID。参见[工作区隐私](/zh/workspace-privacy)。
- **菜单栏图标，更容易找到。**当 macOS 不让 todz 显示在菜单栏时，App 会提示一次，并在你点按时打开**菜单栏**设置。
- 打开面板时，输入框会自动获得焦点；同时刷新连接的智能体会保持连接。

## 0.2.8

**重大变更：API 密钥已移除。**

- 项目密钥和所有者密钥不再有效，服务器已删除所有已存储的密钥。每个 MCP 客户端都只用 OAuth 连接。
- 仍然发送密钥的客户端会收到 401，并指向[连接智能体](/zh/connect-an-agent)。要重新连接，请运行 `claude mcp add --transport http todz https://api.todz.app/mcp` 并登录。
- Mac App 的**连接智能体**界面现在只显示不带密钥的 OAuth 命令，另有**已连接的应用**，可在那里断开某个应用。

其他新内容：

- 菜单栏弹出窗口全新设计：日环和计数、**下一项**卡片、玻璃质感的输入框、安静的队列，以及折叠起来的**今天已完成**。**更多**菜单里有**退出**、**检查更新…**、**在 GitHub 上加星**和**切换工作区…**。⌘O 打开 todz，空格键完成任务，⌘↩ 完成**下一项**。参见[键盘快捷键](/zh/keyboard-shortcuts)。
- 锁定的工作区会话看起来就像只有一个工作区的账户。锁定时，**切换工作区…**（⌘K）会要求 Touch ID，设置选项的名称是**切换工作区需要 Touch ID**。参见[工作区](/zh/workspaces)。
- 统一的动效系统。开启**减弱动态效果**时，所有动画都会变成交叉淡化或即时变化。
- 一个具有账户范围的 OAuth 连接可使用所有工具，包括任务工具，且每个任务工具都要明确指定项目。参见 [MCP 工具](/zh/mcp-tools)。

## 0.2.7

- 设置里新增工作区锁，默认关闭：切换工作区之前需要 Touch ID 或 Mac 密码。参见[工作区](/zh/workspaces)。
- 菜单栏计数会滚动，新行会弹入，边栏标题会飞向工具栏。
- 设置会列出连接到你账户的 App，并可断开其中任何一个。

## 0.2.6

- todz 会主动提出把自己移入**应用程序**，仅在你点按时、且没有 todz 在运行时才会这样做。它绝不会替换已安装的 todz。

## 0.2.5

- 表单拥有统一的外观：名称面板、第一个工作区、需键入名称的确认、服务器输入框和登录，都放在玻璃质感的面板里。
- 录制快捷键的那一行会显示它正在监听，**连接智能体**有了圆角的区块和带警示色的**撤销**。

## 0.2.4

- App 会丢弃被智能体删除或移走的任务。
- 设置会显示服务器的合理使用提示，并管理你的账户密钥。参见[合理使用](/zh/fair-use)。
- 云端已满或达到每日上限时，App 会把你的更改保留在队列中，并暂停发送，直到它们能够同步。

## 0.2.3

- 可在**工作区**菜单中重命名和删除工作区，也可以删除项目。
- 工作区会显示其最近的活动。
- 全局工作区快捷键在你开启之前保持关闭，并且只在组合键空闲时才注册。
- **新建项目**固定在边栏列表下方。

## 0.2.2

- 工作区快捷键：⌃1 … ⌃9、⌃⌘[ 和 ⌃⌘]，可重新绑定，可在任何 App 中使用。参见[工作区](/zh/workspaces)。
- 可以同时显示多个工作区，或显示**所有工作区**，并按工作区加上标记。
- 弹出窗口和 todz 菜单中新增**在 GitHub 上为 todz 加星**，设置中新增**GitHub 上的开源项目**。
- 磁盘映像有了背景图。
- **共享匿名使用数据**，在你说“是”之前保持关闭。参见[隐私](/zh/privacy)。

## 0.2.1

App 没有任何变化。这是第一次通过 Sparkle 推送的更新，用来检查 0.2.0 的安装能否自行更新。

## 0.2.0

第一个公开下载版本。

- App 通过 Sparkle 自行更新。参见[更新](/zh/updates)。
- 为拥有多个工作区的账户提供工作区选择器。
- 动效：对勾带着薄荷色迸发的效果绘出，弹出窗口绽放，晨间速览和收工总结滑入。
- 菜单栏丝带、收工总结、晨间速览和每日邮件。
