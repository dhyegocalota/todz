---
title: 키보드 단축키
description: 목록과 워크스페이스의 단축키.
---

| 키 | 동작 |
| --- | --- |
| ⌘N | **새 작업** |
| ⇧⌘N | **새 프로젝트…** |
| ⌘R | **새로 고침** |
| ⌥⌘I | **인스펙터 보기**와 **인스펙터 가리기** |
| ⌘K | **워크스페이스 전환…**, 잠금이 켜져 있으면 Touch ID를 요청해요 |
| ⌘1 … ⌘9 | 팝오버와 워크스페이스 메뉴에서 워크스페이스 전환 |
| ⌃1 … ⌃9 | todz가 맨 앞에 있을 때 워크스페이스 1 … 9로 이동 |
| ⌃⌘[ | todz가 맨 앞에 있을 때 **이전 워크스페이스** |
| ⌃⌘] | todz가 맨 앞에 있을 때 **다음 워크스페이스** |
| ⌃⌥⌘1 … ⌃⌥⌘9 | **모든 앱에서 전환**이 켜져 있으면(기본값은 꺼짐) 어떤 앱에서든 워크스페이스 1 … 9로 이동 |

메뉴 막대 팝오버에서는 이래요.

| 키 | 동작 |
| --- | --- |
| ⌘O | todz 열기 |
| ⌘N | **작업 추가**에 포커스 |
| ↓ 및 ↑ | 카드, 행, **오늘 완료**를 따라 이동 |
| Space | 작업을 완료로 표시하거나 다시 열기 |
| Return | todz 윈도우에서 작업 보기 |
| ⌘↩ | **작업 추가**에서 **다음 차례** 작업을 완료로 표시 |

전역 워크스페이스 키는 todz › 설정의 **워크스페이스 단축키**에서 바꿀 수 있어요. 방법과 다른 앱이 같은 조합을 쓰고 있을 때 해야 할 일은 [워크스페이스](/ko/workspaces)에서 알려 줘요.
