todz는 사용 방식을 일별 합계로 집계해요. 누가 무엇을 했는지 기록을 남기지 않고, 이를 위해 작업을 읽지도 않아요.

## 집계하는 것

각 집계는 하루에 대한 숫자 하나이고, 짧은 라벨이 최대 하나 붙어요.

| 집계 | 출처 | 라벨 |
| --- | --- | --- |
| 소유자, 워크스페이스, 프로젝트 | 서버 자체의 기록, 밤마다 한 번 | 없음 |
| 추가된 작업, 완료된 작업 | 각 프로젝트의 집계, 밤마다 한 번 | 없음 |
| 에이전트 쓰기 | 에이전트가 바꾼 항목의 집계, 밤마다 한 번 | 정해진 목록(Claude Code, Codex, Cursor, Gemini, Windsurf, Zed, VS Code)에 있는 에이전트 이름, 그 밖에는 `other` |
| 발송한 하루 메일 | 서버 자체의 기록, 밤마다 한 번 | 없음 |
| 업데이트 확인 | 업데이트를 요청하는 Mac 앱 | 앱 버전과 macOS 메이저 버전, 예: `0.2.1\|15` |
| 공유된 사용 보고서 | Mac 앱, **익명 사용 정보 공유**를 켠 경우에만 | 앱 버전과 macOS 메이저 버전 |
| 공유된 사용 이벤트 | 같은 보고서 | `popover_opened`, `day_closed`, `morning_glance`, `shortcut_used`, `multi_workspace` 중 하나 |
| 제거된 연결된 앱 | 앱의 연결이 끝날 때 서버 | `replayed_code`, `eviction`, `reuse_after_rotation`, `cap`, `client_revoke`, `settings_disconnect`, `cascade` 중 하나 |

## 절대 저장하지 않는 것

- 작업 제목, 메모, 프로젝트 이름, 워크스페이스 이름, 이메일 주소는 저장하지 않아요.
- IP 주소와 user agent는 저장하지 않아요. 업데이트 확인의 user agent는 두 버전 번호를 읽는 데만 쓰고 버려요.
- 이벤트 로그도, 개별 이벤트의 타임스탬프도 없어요. 날짜와 합계만 있어요. 유일한 예외로, 앱의 연결이 끝나면 서버가 이유와 앱 이름만 담은 한 줄을 자체 로그에 남겨요. 계정, 주소, 토큰은 담지 않아요.
- Mac 앱이 보고서와 함께 보내는 무작위 코드는 30일마다 바뀌고, 오남용을 늦추는 데만 쓰이며 저장되지 않아요.

합계는 13개월 동안 보관되고 그 뒤에 서버가 삭제해요.

## 익명 사용 정보 공유

Mac 앱은 한 번 물어봐요. 허락하기 전까지는 꺼져 있고, 설정에서 언제든 바꿀 수 있어요. 켜면 앱은 위의 다섯 가지 이벤트의 횟수를 Mac에 쌓아 두고, 하루에 작은 보고서 하나를 보내요. 횟수, 앱 버전, macOS 메이저 버전, 무작위 코드가 들어 있어요. 보고서는 1 KB보다 작고, 서버는 2 KB를 넘는 것은 거부해요.

## 셀프 호스팅

직접 운영하는 서버는 아무것도 집계하지 않아요. `TELEMETRY` 설정은 값이 정확히 `on`일 때만 켜지고, 셀프 호스팅 가이드는 이 설정을 지우라고 안내해요. 내 서버에 로그인한 Mac 앱은 보고서를 내 서버로 보내고, 서버는 이를 거부해요.

## 숫자를 읽는 곳

호스팅 서비스의 소유자만 숫자를 읽을 수 있어요. 로그인한 관리자 페이지에서 CSV 내보내기와 함께 볼 수 있어요. 코드는 공개되어 있어요. 저장소의 `apps/api/src/telemetry`를 보세요.
