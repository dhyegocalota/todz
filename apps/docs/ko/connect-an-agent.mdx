---
title: 에이전트 연결
description: OAuth로 Claude Code, Claude.ai, Codex를 todz에 로그인시켜요. API 키는 없어졌어요.
---

`https://api.todz.app/mcp`의 todz MCP 서버는 MCP OAuth로 클라이언트를 로그인시켜요. 클라이언트에 URL을 추가하세요. 처음 호출하면 브라우저가 열리고, 거기서 앱을 승인해요. OAuth가 연결하는 유일한 방법이에요.

직접 서버를 운영한다면 `https://api.todz.app/mcp` 대신 그 서버의 URL을 쓰세요.

## 호환성이 깨지는 변경: API 키가 없어졌어요

2026-11-27에 todz는 API 키를 없앴어요. 프로젝트 키와 소유자 키는 더 이상 동작하지 않고, 서버는 저장된 키를 모두 삭제했어요. 키를 아직 보내는 클라이언트는 이 페이지를 안내하는 `401`을 받아요.

키를 쓰던 에이전트를 다시 연결하려면 `claude mcp add --transport http todz https://api.todz.app/mcp`를 실행하고 아래 설명대로 로그인하세요. 예전 `Authorization` 헤더를 지우고, 설정해 두었다면 `TODZ_API_KEY` 변수도 지워요. 같은 업데이트에서 Mac 앱의 **에이전트 연결** 화면도 없어졌어요.

## OAuth로 로그인

1. todz 이메일을 입력하고 확인을 통과해요.
2. 메일의 로그인 링크를 **같은 브라우저에서** 열어요.
3. 동의 화면을 읽어 보세요. 앱의 이름과 돌아갈 위치가 적혀 있어요.
4. 프로젝트를 하나 골라요. 첫 번째 프로젝트가 미리 선택되어 있어요. 아니면 **계정 전체(소유자 범위)**를 고를 수 있어요. 이 항목은 미리 선택되지 않으며 "모든 작업을 읽고 바꿀 수 있고, 모든 워크스페이스와 프로젝트를 만들고 이름을 바꾸고 삭제할 수 있어요."라는 경고가 나와요.
5. 승인하거나 거부해요.

프로젝트 범위는 작업 도구와, `move`와 `projects`를 위한 같은 워크스페이스의 다른 프로젝트 접근을 줘요. 소유자 범위는 계정 도구와, 계정의 모든 프로젝트에 대한 같은 작업 도구를 줘요. 이때 각 도구는 `workspaces`에서 얻은 `project` id를 받아요. 작업 기록에는 앱이 등록한 이름으로 앱이 표시돼요. [MCP 도구](/ko/mcp-tools)를 참고하세요.

액세스 토큰은 한 시간 동안 유효하고 스스로 갱신돼요. 리프레시 토큰은 30일 동안 유효하고 사용할 때마다 교체돼요. 하나가 두 번 쓰이면 그 앱은 연결이 끊겨요. todz는 토큰을 다이제스트로만 저장해요. 공정 사용과 클라우드 한도는 연결된 모든 앱에 적용돼요.

앱의 연결을 끊으려면 Mac 앱에서 **설정** › **연결된 앱**을 여세요. 그 앱은 즉시 멈춰요.

리디렉션 주소는 `https`이거나 루프백 주소(`127.0.0.1`, `localhost`, `[::1]`)여야 해요. 사양이 요구하는 대로 사용자 지정 스킴은 거부돼요.

### Claude Code

```bash
claude mcp add --transport http todz https://api.todz.app/mcp
```

그런 다음 Claude Code에서 `/mcp`를 실행하고 todz를 골라 로그인하세요. Claude Code가 브라우저를 열어 줘요.

### Claude.ai와 Claude Desktop

**설정** › **커넥터** › **커스텀 커넥터 추가**를 열고, URL로 `https://api.todz.app/mcp`를 입력한 다음 **연결**을 누르세요.

### Codex

`~/.codex/config.toml`에 다음을 추가하세요.

```toml
[mcp_servers.todz]
url = "https://api.todz.app/mcp"
```

그런 다음 로그인해요.

```bash
codex mcp login todz
```

### Cursor

Cursor는 `cursor://` 주소로 MCP 서버에 로그인하는데, MCP 사양이 허용하지 않아서 todz는 거부해요. Cursor가 `https`나 루프백 주소로 로그인하게 되기 전까지는 todz에 연결할 수 없어요.
