모든 릴리스는 [github.com/dhyegocalota/todz/tags](https://github.com/dhyegocalota/todz/tags)의 `mac-v<version>`이라는 이름의 GitHub 태그예요. 앱은 [todz.app/download/appcast.xml](https://todz.app/download/appcast.xml)을 읽어서 스스로 업데이트해요.

## 0.2.9

**todz가 열 가지 언어를 말해요.** 앱, 위젯, todz.app, 이메일, 이 문서가 English, Português (Brasil), Español, Deutsch, Français, 日本語, 한국어, 简体中文, العربية, हिन्दी로 제공돼요. 앱은 Mac의 언어를 따라가고, 설정 › 일반의 **언어**에서 다른 언어를 고를 수 있어요. **모양**(시스템, 라이트, 다크)도 같은 곳에 있어요. 아랍어는 오른쪽에서 왼쪽으로 읽어요.

- **코드로 로그인.** 로그인 이메일에 링크와 함께 여섯 자리 코드가 들어 있어요. 앱에 입력하거나 붙여 넣으세요. 둘 중 하나로 로그인되고, 하나를 쓰면 둘 다 사용된 것으로 처리돼요.
- **에이전트가 접근하는 범위를 정확히 고르세요.** 앱을 연결할 때 계정 전체를 고르거나 워크스페이스와 프로젝트를 원하는 대로 섞어서 고를 수 있어요. 설정의 **연결된 앱**은 각 앱의 접근 범위를 쉬운 말로 보여 주고, 범위를 제한하거나 연결을 끊을 수 있게 해 줘요.
- **작업 삭제.** **작업 삭제…**는 윈도우와 팝오버 모두에서 작업의 컨텍스트 메뉴, 작업 메뉴, ⌘⌫에 있어요. 먼저 확인을 물어보고, 취소가 기본값이에요.
- **더 분명해진 워크스페이스.** 워크스페이스 전환기에서 클릭하면 그 워크스페이스가 보이고, ⌘-클릭이나 **함께 보기**는 하나를 더 추가해요. 워크스페이스 잠금을 켜면 잠길 때 열려 있던 워크스페이스는 계속 보이고, 다른 워크스페이스에 접근할 때는 Touch ID를 요청해요. [워크스페이스 보호](/ko/workspace-privacy)를 참고하세요.
- **찾기 쉬워진 메뉴 막대 아이템.** macOS가 todz를 메뉴 막대에 표시하지 않으면 앱이 한 번 알려 주고, 클릭하면 **메뉴 막대** 설정을 열어요.
- 시트가 열리면 입력란에 저절로 포커스가 가고, 같은 순간에 연결을 갱신하는 에이전트도 연결이 유지돼요.

## 0.2.8

**호환성이 깨지는 변경: API 키가 없어졌어요.**

- 프로젝트 키와 소유자 키는 더 이상 동작하지 않고, 서버는 저장된 키를 모두 삭제했어요. 모든 MCP 클라이언트는 OAuth로만 연결해요.
- 키를 아직 보내는 클라이언트는 [에이전트 연결](/ko/connect-an-agent)을 안내하는 401을 받아요. 다시 연결하려면 `claude mcp add --transport http todz https://api.todz.app/mcp`를 실행하고 로그인하세요.
- Mac 앱의 **에이전트 연결** 화면에는 이제 키 없이 OAuth 명령만 나오고, 앱 연결을 끊는 **연결된 앱**이 함께 있어요.

그 밖에 새로운 점이에요.

- 메뉴 막대 팝오버를 새로 디자인했어요. 하루 링과 개수, **다음 차례** 카드, 유리 같은 입력창, 조용한 대기열, 접힌 **오늘 완료**로 이루어져요. **더 보기** 메뉴에는 **종료**, **업데이트 확인…**, **GitHub에서 별표**, **워크스페이스 전환…**이 들어 있어요. ⌘O는 todz를 열고, Space는 완료로 표시하고, ⌘↩는 **다음 차례**를 완료로 표시해요. [키보드 단축키](/ko/keyboard-shortcuts)를 참고하세요.
- 잠긴 워크스페이스 세션은 워크스페이스가 하나뿐인 계정처럼 보여요. 잠겨 있는 동안 **워크스페이스 전환…**(⌘K)은 Touch ID를 요청하고, 설정 항목은 **워크스페이스를 전환하려면 Touch ID 필요**로 바뀌었어요. [워크스페이스](/ko/workspaces)를 참고하세요.
- 하나로 통일된 모션 시스템이에요. **동작 줄이기**를 켜면 모든 애니메이션이 크로스페이드나 즉시 전환으로 바뀌어요.
- 계정 범위로 OAuth 연결 하나만 있으면 작업 도구를 포함한 모든 도구를 쓸 수 있고, 각 작업 도구는 프로젝트를 명시적으로 받아요. [MCP 도구](/ko/mcp-tools)를 참고하세요.

## 0.2.7

- 설정에 워크스페이스 잠금이 생겼어요. 기본값은 꺼짐이고, 워크스페이스를 전환하기 전에 Touch ID나 Mac 암호를 요청해요. [워크스페이스](/ko/workspaces)를 참고하세요.
- 메뉴 막대의 개수가 굴러가고, 새 행이 튀어 들어오고, 사이드바 제목이 툴바로 날아가요.
- 설정에 계정에 연결된 앱 목록이 나오고, 앱 하나의 연결을 끊을 수 있어요.

## 0.2.6

- todz가 스스로를 **응용 프로그램** 폴더로 옮기자고 제안해요. 직접 클릭했을 때만, 그리고 실행 중인 todz가 없을 때만 제안해요. 설치된 todz를 덮어쓰는 일은 없어요.

## 0.2.5

- 폼이 하나의 모습을 공유해요. 이름 시트, 첫 워크스페이스, 이름을 직접 입력하는 확인, 서버 입력란, 로그인이 모두 유리 패널에 담겨요.
- 단축키 기록 행은 듣고 있다는 것을 보여 주고, **에이전트 연결**에는 둥근 블록과 위험을 알리는 **해제** 버튼이 생겼어요.

## 0.2.4

- 에이전트가 삭제하거나 다른 곳으로 옮긴 작업을 앱이 지워요.
- 설정에 서버의 공정 사용 메시지가 표시되고 계정 키를 관리할 수 있어요. [공정 사용](/ko/fair-use)을 참고하세요.
- 클라우드가 가득 찼거나 일일 한도에 도달하면 앱이 변경 사항을 대기열에 보관하고, 동기화할 수 있을 때까지 전송을 멈춰요.

## 0.2.3

- **워크스페이스** 메뉴에서 워크스페이스의 이름을 바꾸고 삭제할 수 있고, 프로젝트도 삭제할 수 있어요.
- 워크스페이스에 마지막 활동이 표시돼요.
- 전역 워크스페이스 단축키는 켜기 전까지 꺼져 있고, 비어 있을 때만 등록돼요.
- **새 프로젝트**가 사이드바 목록 아래에 고정돼요.

## 0.2.2

- 워크스페이스 단축키: ⌃1 … ⌃9, ⌃⌘[, ⌃⌘]. 바꿀 수 있고, 어떤 앱에서든 쓸 수 있어요. [워크스페이스](/ko/workspaces)를 참고하세요.
- 여러 워크스페이스를 한꺼번에, 또는 **모든 워크스페이스**로 보고, 워크스페이스별로 태그가 붙어요.
- 팝오버와 todz 메뉴에 **GitHub에서 todz에 별표 표시**, 설정에 **GitHub의 오픈 소스**가 생겼어요.
- 디스크 이미지 배경이 생겼어요.
- **익명 사용 정보 공유**는 허락하기 전까지 꺼져 있어요. [개인정보 보호](/ko/privacy)를 참고하세요.

## 0.2.1

앱에는 달라진 점이 없어요. Sparkle로 전달한 첫 업데이트로, 0.2.0 설치본이 스스로 업데이트되는지 확인하기 위한 것이에요.

## 0.2.0

처음으로 공개된 다운로드예요.

- 앱이 Sparkle로 스스로 업데이트해요. [업데이트](/ko/updates)를 참고하세요.
- 워크스페이스가 여러 개인 계정을 위한 워크스페이스 선택 화면.
- 모션: 체크 표시가 민트빛 파동과 함께 그려지고, 팝오버가 피어나며, 아침 요약과 하루 마감이 미끄러져 들어와요.
- 메뉴 막대 리본, 하루 마감, 아침 요약, 하루 이메일.
