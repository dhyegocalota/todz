title: MCP 도구
description: todz MCP 서버가 에이전트에게 제공하는 도구와 프롬프트, 그리고 각각에 필요한 범위.
---

MCP 클라이언트는 OAuth로만 todz 서버에 연결해요. [에이전트 연결](/ko/connect-an-agent)에 나온 대로 클라이언트에 URL을 추가하고 로그인하세요. 승인하는 권한이 도구 세트를 정해요. 프로젝트 범위는 프로젝트 하나의 작업 도구를 받고, 소유자 범위는 계정 도구와 계정의 모든 프로젝트에 대한 같은 작업 도구를 받아요. 아래의 각 도구에는 필요한 범위가 적혀 있어요.

- **프로젝트 범위**는 프로젝트 하나의 할 일 목록을 다뤄요. 동의 화면에서 고른 그 프로젝트예요. 그 프로젝트의 워크스페이스 안에서 작업을 나열하고 옮길 수도 있어요. 워크스페이스나 프로젝트를 만들거나 이름을 바꾸거나 삭제하지는 않아요. 작업 id는 `T-12`처럼 생겼어요.
- **소유자 범위**는 계정 전체를 다뤄요. 워크스페이스, 프로젝트, 모든 작업이 대상이라서 연결 하나로 앱이 할 수 있는 모든 일을 할 수 있어요. 동의 화면에서 미리 선택되지 않고, **설정** › **연결된 앱**에서 연결을 끊어요. 다른 계정에는 닿지 않아요.

소유자 범위에서는 모든 작업 도구가 필수 `project` 인수를 받아요. 작업 대상 프로젝트의 id이고, `workspaces`에서 얻어요. 기본 프로젝트는 없어요. 다른 계정의 프로젝트는 존재하지 않는 프로젝트와 똑같이 응답해요. 프로젝트 범위에는 `project` 인수가 없어요. 다만 `move`는 거기서 목적지를 받아요.

모든 삭제는 현재 이름(작업이라면 현재 제목)을 담은 `confirm` 인수를 요구해요. 다르면 아무것도 삭제되지 않아요.

## next

**범위:** 프로젝트 범위와 소유자 범위.

이 프로젝트에서 지금 처리할 열린 작업 하나를 메모와 함께 돌려줘요.

| 인수      | 유형   | 설명                                                             |
| --------- | ------ | ---------------------------------------------------------------- |
| `project` | 텍스트 | 소유자 범위에서만: 작업 도구가 다루는 프로젝트의 id, workspaces에서 얻어요. |

## add

**범위:** 프로젝트 범위와 소유자 범위.

작업을 하나 이상 추가해요. 각 작업에 idempotency_key를 주면 재시도해도 안전해요.

| 인수              | 유형             | 설명                                                                         |
| ----------------- | ---------------- | ---------------------------------------------------------------------------- |
| `project`         | 텍스트           | 소유자 범위에서만: 작업 도구가 다루는 프로젝트의 id, workspaces에서 얻어요.  |
| `tasks`           | 목록             | 추가할 작업, 각각 객체 하나예요.                                             |
| `title`           | 텍스트           | 짧은 제목.                                                                   |
| `notes`           | 텍스트 또는 null | Markdown 메모.                                                               |
| `due_date`        | 텍스트 또는 null | 달력 날짜, YYYY-MM-DD.                                                       |
| `idempotency_key` | 텍스트 또는 null | 이 작업에만 있는 아무 문자열. 반복하면 이미 추가된 작업을 돌려줘요.          |

## list

**범위:** 프로젝트 범위와 소유자 범위.

상태, 기한 범위, 텍스트로 작업을 수동 순서대로 나열해요(완료: 최신순).

| 인수      | 유형            | 설명                                                                                   |
| --------- | --------------- | -------------------------------------------------------------------------------------- |
| `project` | 텍스트          | 소유자 범위에서만: 작업 도구가 다루는 프로젝트의 id, workspaces에서 얻어요.            |
| `state`   | 텍스트          | `open` 또는 `done`. 기본값은 `open`이에요.                                             |
| `due`     | 텍스트 목록     | 포함할 기한 범위: `overdue`, `today`, `upcoming` 또는 `undated`. 비워 두면 모두예요.   |
| `text`    | 텍스트 또는 null | 제목과 메모에서 찾을 텍스트.                                                           |
| `limit`   | 정수            | 보여 줄 작업 수.                                                                       |

## update

**범위:** 프로젝트 범위와 소유자 범위.

작업의 제목, 메모, 기한, 순서에서의 위치를 바꿔요. null은 메모나 기한을 지워요.

| 인수        | 유형             | 설명                                                                       |
| ----------- | ---------------- | -------------------------------------------------------------------------- |
| `project`   | 텍스트           | 소유자 범위에서만: 작업 도구가 다루는 프로젝트의 id, workspaces에서 얻어요. |
| `id`        | 텍스트           | `T-12` 같은 작업 id.                                                       |
| `title`     | 텍스트           | 짧은 제목.                                                                 |
| `notes`     | 텍스트 또는 null | Markdown 메모.                                                             |
| `due_date`  | 텍스트 또는 null | 달력 날짜, YYYY-MM-DD.                                                     |
| `placement` | 객체             | 작업을 옮길 위치: `first`, `last`, 또는 기준 작업의 `before`나 `after`.    |
| `kind`      | 텍스트           | `placement` 안에서: `first`, `last`, `before` 또는 `after`.                |
| `anchor`    | 텍스트           | `placement` 안에서 `before`와 `after`일 때: 기준이 되는 다른 작업의 id.    |

## delete

**범위:** 프로젝트 범위와 소유자 범위.

작업을 완전히 삭제해요. 현재 제목을 confirm으로 주세요. 다르면 아무것도 삭제되지 않아요. 다른 곳에 두려는 작업에는 move가 필요해요. 소유자의 Mac에는 다음 업데이트 뒤에 삭제가 반영돼요.

| 인수      | 유형   | 설명                                                                              |
| --------- | ------ | --------------------------------------------------------------------------------- |
| `project` | 텍스트 | 소유자 범위에서만: 작업 도구가 다루는 프로젝트의 id, workspaces에서 얻어요.       |
| `id`      | 텍스트 | `T-12` 같은 작업 id.                                                              |
| `confirm` | 텍스트 | 작업의 현재 제목을 그대로 입력해요. 다르면 아무것도 삭제되지 않아요.              |

## move

**범위:** 프로젝트 범위와 소유자 범위.

작업을 같은 워크스페이스의 다른 프로젝트로 옮겨요. 작업은 그곳에서 새 id를 받아요. 프로젝트 id는 projects로 찾으세요. 소유자의 Mac에는 다음 업데이트 뒤에 이동이 반영돼요.

| 인수          | 유형   | 설명                                                                                                |
| ------------- | ------ | --------------------------------------------------------------------------------------------------- |
| `id`          | 텍스트 | `T-12` 같은 작업 id.                                                                                |
| `project`     | 텍스트 | 프로젝트 범위: 작업을 옮길 프로젝트의 id, projects 도구에서 얻어요. 소유자 범위: 작업이 있는 프로젝트의 id, workspaces에서 얻어요. |
| `destination` | 텍스트 | 소유자 범위에서만: 작업을 옮길 프로젝트의 id, workspaces에서 얻어요.                                |

## settings

**범위:** 소유자 범위.

계정 설정을 보여 줘요. 시간대, 에이전트 알림, 하루 이메일이에요.

인수는 없어요.

## update_settings

**범위:** 소유자 범위.

계정 설정을 바꿔요. 바뀌는 것만 주세요.

| 인수                | 유형            | 설명                                                                                     |
| ------------------- | --------------- | ---------------------------------------------------------------------------------------- |
| `time_zone`         | 텍스트          | America/Sao_Paulo 같은 시간대 이름.                                                      |
| `agent_nudge`       | 참 또는 거짓    | next가 오늘 마감인 작업에 관한 줄을 덧붙일지 여부.                                       |
| `day_email`         | 참 또는 거짓    | 하루 이메일을 보낼지 여부.                                                               |
| `day_email_minutes` | 정수            | 내 시간대에서 자정 이후 몇 분에 하루 이메일을 보낼지: 0에서 1439.                        |
