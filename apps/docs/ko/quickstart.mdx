## 1. 앱 받기

[todz.app/download](https://todz.app/download)에서 Mac용 todz를 받은 다음, [Mac에 설치](/ko/install-on-mac)해요. 다운로드를 검증하고 **그래도 열기**로 한 번 열어 주세요. 소스에서 직접 빌드할 수도 있어요. [셀프 호스팅 가이드의 빌드 단계](/ko/self-host#7-macos-앱-빌드하고-서버에-연결하기)를 참고하세요. 빌드한 앱은 기본 서버로 todz cloud를 그대로 써요.

## 2. 로그인

이메일을 입력하고 **링크 보내기**를 누른 다음, 요청한 바로 그 Mac에서 메일의 링크를 열어요.

<Note>
  무료 todz cloud 자리는 매우 한정되어 있어요. 클라우드가 가득 차면 받은 메일에서 그렇게 알려 주고 대기열에 참여하는 방법도 안내해요. 셀프 호스팅은 언제나 열려 있어요. [공정 사용](/ko/fair-use#todz-cloud-수용량)과 [셀프 호스팅](/ko/self-host)을 참고하세요.
</Note>

<Note>
  나만의 서버를 운영하나요? 설정의 **서버**에서, 또는 로그인 화면의 서버 줄에서 바꿀 수 있어요. **todz cloud 사용**을 누르면 기본값으로 돌아가요. [셀프 호스팅](/ko/self-host)을 참고하세요.
</Note>

## 3. 다음 단계

프로젝트에 [에이전트를 연결](/ko/connect-an-agent)하면 에이전트가 작업을 처리할 수 있어요. 다른 워크스페이스를 눈에 띄지 않게 하려면 [워크스페이스 보호](/ko/workspace-privacy)를 켜세요.
