todz ist Open Source unter der [AGPL-3.0](https://github.com/dhyegocalota/todz/blob/main/LICENSE). Das ganze Repository steht unter einer Lizenz: die App, der Server, die Bibliotheken und diese Dokumentation.

Der Code liegt unter [github.com/dhyegocalota/todz](https://github.com/dhyegocalota/todz). Wenn dir todz nützt, wähle **todz auf GitHub mit Stern markieren** im Popover oder im todz-Menü. **Open Source auf GitHub** in todz › Einstellungen öffnet das Repository ebenfalls.

## Beitragen

Lies zuerst [CONTRIBUTING](https://github.com/dhyegocalota/todz/blob/main/.github/CONTRIBUTING.md). Beiträge stehen unter der [Contributor License Agreement](https://github.com/dhyegocalota/todz/blob/main/.github/CLA.md). Melde ein Sicherheitsproblem, wie es die [Sicherheitsrichtlinie](https://github.com/dhyegocalota/todz/blob/main/.github/SECURITY.md) beschreibt, niemals in einem öffentlichen Issue.

Um deinen eigenen Server zu betreiben, siehe [Selbst hosten](/de/self-host).
