---
title: Diese Dokumentation aus deinem Agenten nutzen
description: Gib einem Agenten diese Dokumentation über MCP oder eine reine Textdatei.
---

Diese Dokumentation hat einen eigenen MCP-Server. In Claude Code:

```bash
claude mcp add --transport http todz-docs https://docs.todz.app/mcp
```

Für einen Agenten, der reinen Text liest, listet [todz.app/llms.txt](https://todz.app/llms.txt) die Seiten auf, und [todz.app/llms-full.txt](https://todz.app/llms-full.txt) enthält sie vollständig.

Damit ein Agent stattdessen deine Aufgaben bearbeitet, siehe [Agent verbinden](/de/connect-an-agent).
