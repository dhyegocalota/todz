---
title: Tastaturkurzbefehle
description: Die Tasten der Listen und der Workspaces.
---

| Tasten | Aktion |
| --- | --- |
| ⌘N | **Neue Aufgabe** |
| ⇧⌘N | **Neues Projekt…** |
| ⌘R | **Aktualisieren** |
| ⌥⌘I | **Inspektor einblenden** und **Inspektor ausblenden** |
| ⌘⌫ | **Aufgabe löschen…** für die ausgewählte Aufgabe in der Aufgabenliste; es fragt vorher nach |
| ⌘K | **Workspace wechseln…**, fragt nach Touch ID, wenn die Sperre eingeschaltet ist |
| ⌘1 … ⌘9 | Workspace wechseln im Popover und im Workspace-Menü |
| ⌃1 … ⌃9 | Zu Workspace 1 … 9 gehen, solange todz im Vordergrund ist |
| ⌃⌘[ | **Vorheriger Workspace**, solange todz im Vordergrund ist |
| ⌃⌘] | **Nächster Workspace**, solange todz im Vordergrund ist |
| ⌃⌥⌘1 … ⌃⌥⌘9 | Zu Workspace 1 … 9 gehen, aus jeder App, wenn **Aus jeder App wechseln** eingeschaltet ist (standardmäßig aus) |

Im Popover der Menüleiste:

| Tasten | Aktion |
| --- | --- |
| ⌘O | todz öffnen |
| ⌘N | **Aufgabe hinzufügen** fokussieren |
| ↓ und ↑ | Durch die Karte, die Zeilen und **Heute erledigt** gehen |
| Leertaste | Die Aufgabe als erledigt markieren oder wieder öffnen |
| Return | Die Aufgabe im todz-Fenster zeigen |
| ⌘↩ | Die Aufgabe unter „Als Nächstes“ aus **Aufgabe hinzufügen** heraus als erledigt markieren |
| ⌘⌫ | **Aufgabe löschen…** für die fokussierte Zeile; es fragt vorher nach |

Die globalen Workspace-Tasten lassen sich unter **Workspace-Kurzbefehle** in todz › Einstellungen neu belegen. [Workspaces](/de/workspaces) erklärt, wie, und was zu tun ist, wenn eine andere App eine Tastenkombination belegt.
