todz is open source under the [AGPL-3.0](https://github.com/dhyegocalota/todz/blob/main/LICENSE). The whole repository is one license: the app, the server, the libraries and these docs.

The code is at [github.com/dhyegocalota/todz](https://github.com/dhyegocalota/todz). If todz is useful to you, choose **Star todz on GitHub** in the popover or the todz menu. **Open source on GitHub** in todz › Settings opens the repository too.

## Contribute

Read [CONTRIBUTING](https://github.com/dhyegocalota/todz/blob/main/.github/CONTRIBUTING.md) first. Contributions come under the [Contributor License Agreement](https://github.com/dhyegocalota/todz/blob/main/.github/CLA.md). Report a security problem as the [security policy](https://github.com/dhyegocalota/todz/blob/main/.github/SECURITY.md) says, never in a public issue.

To run your own server, see [Self-host todz](/self-host).
