---
title: キーボードショートカット
description: リストとワークスペースのキー。
---

| キー | 操作 |
| --- | --- |
| ⌘N | **新規タスク** |
| ⇧⌘N | **新規プロジェクト…** |
| ⌘R | **更新** |
| ⌥⌘I | **インスペクタを表示**と**インスペクタを非表示** |
| ⌘K | **ワークスペースを切り替える…**。ロックがオンのときはTouch IDを求められます |
| ⌘1 … ⌘9 | ポップオーバとワークスペースメニューでワークスペースを切り替える |
| ⌃1 … ⌃9 | ワークスペース1 … 9に移動する（todzが最前面にあるとき） |
| ⌃⌘[ | **前のワークスペース**（todzが最前面にあるとき） |
| ⌃⌘] | **次のワークスペース**（todzが最前面にあるとき） |
| ⌃⌥⌘1 … ⌃⌥⌘9 | **どのアプリからでも切り替える**がオンのとき、どのアプリからでもワークスペース1 … 9に移動する（デフォルトではオフ） |

メニューバーのポップオーバでは次のとおりです。

| キー | 操作 |
| --- | --- |
| ⌘O | todzを開く |
| ⌘N | **タスクを追加**にフォーカスする |
| ↓と↑ | カード、行、**今日完了**の間を移動する |
| スペース | タスクを完了にする、または再び開く |
| Return | todzウィンドウにタスクを表示する |
| ⌘↩ | **タスクを追加**から、**次にやること**のタスクを完了にする |

グローバルなワークスペースのキーは、todz › 設定の**ワークスペースのショートカット**で再設定できます。方法と、ほかのアプリがキーの組み合わせを使っているときの対処は、[ワークスペース](/ja/workspaces)をご覧ください。
