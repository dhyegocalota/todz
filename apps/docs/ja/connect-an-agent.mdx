---
title: エージェントを接続する
description: OAuthでClaude Code、Claude.ai、Codexをtodzにサインインさせます。APIキーは廃止されました。
---

`https://api.todz.app/mcp`にあるtodzのMCPサーバは、MCP OAuthでクライアントをサインインさせます。クライアントにこのURLを追加してください。最初の呼び出しでブラウザが開くので、そこでアプリを承認します。接続できるのはOAuthだけです。

独自のサーバを動かしている場合は、`https://api.todz.app/mcp`の代わりにそのURLを使ってください。

## 破壊的変更：APIキーの廃止

2026-11-27に、todzはAPIキーを廃止しました。プロジェクトキーとオーナーキーは使えなくなり、サーバは保存されていたキーをすべて削除しました。キーを送り続けるクライアントには、このページへの案内とともに`401`が返ります。

キーを使っていたエージェントを再接続するには、`claude mcp add --transport http todz https://api.todz.app/mcp`を実行し、以下の手順でサインインしてください。古い`Authorization`ヘッダと、設定していた場合は`TODZ_API_KEY`変数を削除します。Macアプリの**エージェントを接続**画面も、同じアップデートでなくなりました。

## OAuthでサインインする

1. todzのメールアドレスを入力し、確認を通過します。
2. メールのサインインリンクを**同じブラウザで**開きます。
3. 同意画面を確認します。アプリの名前と、戻り先が表示されます。
4. アプリが使えるものにチェックを入れます。ワークスペースをまるごと、またはそのプロジェクトの一部だけを、どのワークスペースからでも選べます。あらかじめ選択されているものはなく、同じアプリがすでに持っているものが1行で表示されます。または、**アカウント全体（オーナースコープ）**にチェックを入れます。「すべてのタスクの読み取りと変更、およびすべてのワークスペースとプロジェクトの作成、名前変更、削除ができます。」と警告が表示されます。
5. 承認するか、拒否します。

1つのプロジェクトでは、タスクのツールに加えて、`move`と`projects`のためにそのワークスペース内のほかのプロジェクトも使えます。複数のプロジェクトやワークスペースでは、タスクのツールだけが使え、各ツールは`workspaces`で調べた`project`のIDを受け取ります。そこにはチェックを入れたものだけが表示されます。チェックを入れたワークスペースは、今後追加されるものを含むすべてのプロジェクトを対象にし、選択の外のプロジェクトは見つからないものとして応答します。オーナースコープでは、アカウントのツールと、アカウント内のすべてのプロジェクトに対する同じタスクのツールが使えます。タスクの履歴には、アプリが登録した名前でそのアプリが記録されます。**設定**›**接続済みのアプリ**で、アプリが使えるものを絞り込んだり、取り消したりできます。[MCPツール](/ja/mcp-tools)をご覧ください。

アクセストークンの有効期間は1時間で、自動的に更新されます。リフレッシュトークンの有効期間は30日で、使うたびにローテーションします。新しいトークンが使われるまでは再試行に新しいペアが発行され、その後に使用済みのトークンが再び使われると、そのアプリは切断されます。todzはトークンをダイジェストとしてのみ保存します。フェアユースとクラウドの上限は、接続されたすべてのアプリに適用されます。

アプリを切断するには、Macアプリで**設定** › **接続済みのアプリ**を開きます。アプリはすぐに停止します。

リダイレクト先のアドレスは、`https`かループバックアドレス（`127.0.0.1`、`localhost`、`[::1]`）でなければなりません。仕様の定めに従い、カスタムスキームは拒否されます。

### Claude Code

```bash
claude mcp add --transport http todz https://api.todz.app/mcp
```

続いて、Claude Codeで`/mcp`を実行し、todzを選んでサインインします。Claude Codeがブラウザを開きます。

### Claude.aiとClaude Desktop

**Settings** › **Connectors** › **Add custom connector**を開き、URLに`https://api.todz.app/mcp`を入力して、**Connect**を押します。

### Codex

`~/.codex/config.toml`に次を追加します。

```toml
[mcp_servers.todz]
url = "https://api.todz.app/mcp"
```

続いて、サインインします。

```bash
codex mcp login todz
```

### Cursor

Cursorは`cursor://`アドレスでMCPサーバにサインインしますが、MCP仕様はこれを認めておらず、todzも拒否します。Cursorが`https`またはループバックアドレスでサインインするようになるまで、Cursorはtodzに接続できません。
