---
title: MCPツール
description: todzのMCPサーバがエージェントに提供するツールとプロンプト、そして各ツールに必要なスコープ。
---

MCPクライアントは、OAuthだけでtodzのサーバに接続します。[エージェントを接続する](/ja/connect-an-agent)のとおり、クライアントにURLを追加してサインインしてください。承認したグラントによって、使えるツールのセットが決まります。プロジェクトスコープでは1つのプロジェクトのタスクのツールが使え、オーナースコープではアカウントのツールと、アカウント内のすべてのプロジェクトに対する同じタスクのツールが使えます。以下の各ツールには、必要なスコープが記載されています。

- **プロジェクトスコープ**は、1つのプロジェクト、つまり同意画面で選んだプロジェクトのToDoリストを扱います。そのプロジェクトのワークスペース内で、タスクの一覧表示と移動もできます。ワークスペースやプロジェクトの作成、名前変更、削除は一切できません。タスクのIDは`T-12`のような形式です。
- **オーナースコープ**は、アカウント全体、つまりワークスペース、プロジェクト、すべてのタスクを扱うため、1つの接続でアプリにできることがすべて使えます。同意画面であらかじめ選択されることはなく、**設定** › **接続済みのアプリ**で切断します。ほかのアカウントには届きません。

オーナースコープでは、すべてのタスクのツールが必須の`project`引数を受け取ります。これは、対象のプロジェクトのIDで、`workspaces`で調べます。デフォルトのプロジェクトはありません。ほかのアカウントのプロジェクトには、存在しないプロジェクトとまったく同じ応答が返ります。プロジェクトスコープには`project`引数がありませんが、`move`だけは移動先を受け取ります。

すべての削除には、現在の名前（タスクの場合は現在のタイトル）を入れた`confirm`引数が必要です。一致しない場合は、何も削除されません。

## next

**スコープ：**プロジェクトスコープとオーナースコープ。

このプロジェクトで今取り組むべき、未完了のタスク1件とそのメモ。

| 引数  | 型   | 説明                                                      |
| --------- | ------ | ---------------------------------------------------------------- |
| `project` | テキスト   | オーナースコープのみ：タスクのツールが扱うプロジェクトのID。workspacesで調べます。 |

## add

**スコープ：**プロジェクトスコープとオーナースコープ。

1件以上のタスクを追加します。それぞれにidempotency_keyを付けると、再試行を安全に行えます。

| 引数          | 型           | 説明                                                                  |
| ----------------- | -------------- | ---------------------------------------------------------------------------- |
| `project`         | テキスト           | オーナースコープのみ：タスクのツールが扱うプロジェクトのID。workspacesで調べます。 |
| `tasks`           | リスト           | 追加するタスク。1件ごとに1つのオブジェクト。                                           |
| `title`           | テキスト           | 短いタイトル。                                                               |
| `notes`           | テキストまたはnull   | Markdownのメモ。                                                            |
| `due_date`        | テキストまたはnull   | カレンダーの日付、YYYY-MM-DD。                                            |
| `idempotency_key` | テキストまたはnull   | このタスクに固有の任意の文字列。繰り返すと、すでに追加されたタスクが返ります。 |

## list

**スコープ：**プロジェクトスコープとオーナースコープ。

状態、期限の範囲、テキストでタスクを一覧表示します。順序は手動の並び順です（完了済みは新しい順）。

| 引数  | 型            | 説明                                                                            |
| --------- | --------------- | -------------------------------------------------------------------------------------- |
| `project` | テキスト            | オーナースコープのみ：タスクのツールが扱うプロジェクトのID。workspacesで調べます。           |
| `state`   | テキスト            | `open`または`done`。デフォルトは`open`です。                                                  |
| `due`     | テキストのリスト    | 含める期限の範囲：`overdue`、`today`、`upcoming`、`undated`。空の場合はすべてです。 |
| `text`    | テキストまたはnull    | タイトルとメモから探すテキスト。                                                     |
| `limit`   | 整数    | 表示するタスクの件数。                                                                   |

## show

**スコープ：**プロジェクトスコープとオーナースコープ。

1件のタスクを、その状態、期限、メモとともに表示します。

| 引数  | 型   | 説明                                                                  |
| --------- | ------ | ---------------------------------------------------------------------------- |
| `project` | テキスト   | オーナースコープのみ：タスクのツールが扱うプロジェクトのID。workspacesで調べます。 |
| `id`      | テキスト   | `T-12`のようなタスクID。                                                        |

## history

**スコープ：**プロジェクトスコープとオーナースコープ。

タスクに何が起きたかを、古い順に表示します。誰が、何を、いつ行ったか。

| 引数  | 型   | 説明                                                                  |
| --------- | ------ | ---------------------------------------------------------------------------- |
| `project` | テキスト   | オーナースコープのみ：タスクのツールが扱うプロジェクトのID。workspacesで調べます。 |
| `id`      | テキスト   | `T-12`のようなタスクID。                                                        |

## update

**スコープ：**プロジェクトスコープとオーナースコープ。

タスクのタイトル、メモ、期限、順序内の位置を変更します。nullを指定すると、メモまたは期限がクリアされます。

| 引数    | 型           | 説明                                                                |
| ----------- | -------------- | -------------------------------------------------------------------------- |
| `project`   | テキスト           | オーナースコープのみ：タスクのツールが扱うプロジェクトのID。workspacesで調べます。 |
| `id`        | テキスト           | `T-12`のようなタスクID。                                                      |
| `title`     | テキスト           | 短いタイトル。                                                               |
| `notes`     | テキストまたはnull   | Markdownのメモ。                                                              |
| `due_date`  | テキストまたはnull   | カレンダーの日付、YYYY-MM-DD。                                              |
| `placement` | オブジェクト         | タスクの移動先：`first`、`last`、または基準タスクの`before`か`after`。 |
| `kind`      | テキスト           | `placement`の中：`first`、`last`、`before`、`after`。                  |
| `anchor`    | テキスト           | `placement`の中で、`before`と`after`とともに指定：もう一方のタスクのID。   |

## done

**スコープ：**プロジェクトスコープとオーナースコープ。

1件以上のタスクを完了します。何をしたかのメモを任意で付けられます。

| 引数  | 型           | 説明                                                                  |
| --------- | -------------- | ---------------------------------------------------------------------------- |
| `project` | テキスト           | オーナースコープのみ：タスクのツールが扱うプロジェクトのID。workspacesで調べます。 |
| `ids`     | テキストのリスト   | `T-12`のようなタスクID。                                                       |
| `note`    | テキストまたはnull   | 何をしたか。                                                               |

**スコープ：**プロジェクトスコープとオーナースコープ。

完了済みのタスクを1件以上、再び開きます。

| 引数  | 型           | 説明                                                                  |
| --------- | -------------- | ---------------------------------------------------------------------------- |
| `project` | テキスト           | オーナースコープのみ：タスクのツールが扱うプロジェクトのID。workspacesで調べます。 |
| `ids`     | テキストのリスト   | `T-12`のようなタスクID。                                                       |

## delete

**スコープ：**プロジェクトスコープとオーナースコープ。

タスクを完全に削除します。confirmには現在のタイトルを指定してください。一致しない場合は、何も削除されません。別の場所に残したいタスクには、moveが必要です。オーナーのMacには、次のアップデート後に削除が反映されます。

| 引数  | 型   | 説明                                                                       |
| --------- | ------ | --------------------------------------------------------------------------------- |
| `project` | テキスト   | オーナースコープのみ：タスクのツールが扱うプロジェクトのID。workspacesで調べます。      |
| `id`      | テキスト   | `T-12`のようなタスクID。                                                             |
| `confirm` | テキスト   | タスクの現在のタイトルを、そのとおりに入力します。一致しない場合は、何も削除されません。 |

## move

**スコープ：**プロジェクトスコープとオーナースコープ。

タスクを、同じワークスペースの別のプロジェクトに移動します。タスクには、移動先で新しいIDが付きます。プロジェクトのIDはprojectsで調べます。オーナーのMacには、次のアップデート後に移動が反映されます。

| 引数      | 型   | 説明                                                                                         |
| ------------- | ------ | --------------------------------------------------------------------------------------------------- |
| `id`          | テキスト   | `T-12`のようなタスクID。                                                                               |
| `project`     | テキスト   | プロジェクトスコープ：タスクの移動先のプロジェクトのID。projectsツールで調べます。オーナースコープ：タスクがあるプロジェクトのID。workspacesで調べます。 |
| `destination` | テキスト   | オーナースコープのみ：タスクの移動先のプロジェクトのID。workspacesで調べます。                           |

## projects

**スコープ：**プロジェクトスコープ。

この接続が属するワークスペースのプロジェクトを、IDとともに一覧表示します。

引数はありません。

## workspaces

**スコープ：**オーナースコープ。

このアカウントのワークスペースを、プロジェクトとIDとともに一覧表示します。

引数はありません。

## create_workspace

**スコープ：**オーナースコープ。

ワークスペースを作成します。最初はインボックスのプロジェクトから始まります。

| 引数 | 型   | 説明                         |
| -------- | ------ | ----------------------------------- |
| `name`   | テキスト   | 名前。80文字まで。          |

## rename_workspace

**スコープ：**オーナースコープ。

ワークスペースの名前を変更します。

| 引数    | 型   | 説明                         |
| ----------- | ------ | ----------------------------------- |
| `workspace` | テキスト   | ワークスペースのID。workspacesで調べます。 |
| `name`      | テキスト   | 名前。80文字まで。          |

## delete_workspace

**スコープ：**オーナースコープ。

ワークスペースを、そのすべてのプロジェクトとタスクとともに完全に削除します。confirmには現在の名前を指定してください。一致しない場合は、何も削除されません。

| 引数    | 型   | 説明                                                                          |
| ----------- | ------ | ------------------------------------------------------------------------------------ |
| `workspace` | テキスト   | ワークスペースのID。workspacesで調べます。                                                |
| `confirm`   | テキスト   | ワークスペースの現在の名前を、そのとおりに入力します。一致しない場合は、何も削除されません。 |

## create_project

**スコープ：**オーナースコープ。

ワークスペースにプロジェクトを作成します。

| 引数    | 型   | 説明                         |
| ----------- | ------ | ----------------------------------- |
| `workspace` | テキスト   | ワークスペースのID。workspacesで調べます。 |
| `name`      | テキスト   | 名前。80文字まで。          |

## rename_project

**スコープ：**オーナースコープ。

プロジェクトの名前を変更します。インボックスの名前は変更できません。

| 引数  | 型   | 説明                         |
| --------- | ------ | ----------------------------------- |
| `project` | テキスト   | プロジェクトのID。workspacesで調べます。 |
| `name`    | テキスト   | 名前。80文字まで。          |

## delete_project

**スコープ：**オーナースコープ。

プロジェクトを、そのタスクとともに完全に削除します。confirmには現在の名前を指定してください。一致しない場合は、何も削除されません。インボックスは削除できません。

| 引数  | 型   | 説明                                                                         |
| --------- | ------ | ----------------------------------------------------------------------------------- |
| `project` | テキスト   | プロジェクトのID。workspacesで調べます。                                                 |
| `confirm` | テキスト   | プロジェクトの現在の名前を、そのとおりに入力します。一致しない場合は、何も削除されません。 |

## settings

**スコープ：**オーナースコープ。

アカウントの設定を表示します：タイムゾーン、エージェントのナッジ、1日のメール。

引数はありません。

## update_settings

**スコープ：**オーナースコープ。

アカウントの設定を変更します。変更する項目だけを指定してください。

| 引数            | 型            | 説明                                                                              |
| ------------------- | --------------- | ---------------------------------------------------------------------------------------- |
| `time_zone`         | テキスト            | America/Sao_Pauloのようなタイムゾーン名。                                                  |
| `agent_nudge`       | 真偽値   | nextが、今日が期限のタスクについての1行を追加するかどうか。                                   |
| `day_email`         | 真偽値   | 1日のメールを送信するかどうか。                                                 |
| `day_email_minutes` | 整数    | 1日のメールを送信する時刻。あなたのタイムゾーンの午前0時からの分数：0〜1439。        |

## プロンプト

サーバは、`next`というプロンプトを1つ提供します。このプロジェクトの次のタスクに取りかかりましょう。
