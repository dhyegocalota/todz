---
title: कीबोर्ड शॉर्टकट
description: सूचियों और वर्कस्पेस की कुंजियाँ।
---

| कुंजियाँ | क्रिया |
| --- | --- |
| ⌘N | **नया टास्क** |
| ⇧⌘N | **नया प्रोजेक्ट…** |
| ⌘R | **रीफ़्रेश करें** |
| ⌥⌘I | **इंस्पेक्टर दिखाएँ** और **इंस्पेक्टर छिपाएँ** |
| ⌘⌫ | टास्क सूची में चुने हुए टास्क पर **टास्क हटाएँ…**; यह पहले पूछता है |
| ⌘K | **वर्कस्पेस बदलें…**, जो लॉक चालू होने पर Touch ID माँगता है |
| ⌘1 … ⌘9 | पॉपओवर और वर्कस्पेस मेन्यू में वर्कस्पेस बदलें |
| ⌃1 … ⌃9 | वर्कस्पेस 1 … 9 पर जाएँ, जब todz सबसे आगे हो |
| ⌃⌘[ | **पिछला वर्कस्पेस**, जब todz सबसे आगे हो |
| ⌃⌘] | **अगला वर्कस्पेस**, जब todz सबसे आगे हो |
| ⌃⌥⌘1 … ⌃⌥⌘9 | किसी भी ऐप से वर्कस्पेस 1 … 9 पर जाएँ, जब **किसी भी ऐप से बदलें** चालू हो (डिफ़ॉल्ट रूप से बंद) |

मेन्यू बार पॉपओवर में:

| कुंजियाँ | क्रिया |
| --- | --- |
| ⌘O | todz खोलें |
| ⌘N | **टास्क जोड़ें** पर फ़ोकस करें |
| ↓ और ↑ | कार्ड, पंक्तियों और **आज पूरे हुए** में आगे-पीछे जाएँ |
| Space | टास्क को पूरा के रूप में चिह्नित करें, या उसे दोबारा खोलें |
| Return | टास्क को todz विंडो में दिखाएँ |
| ⌘↩ | **टास्क जोड़ें** से ही अगला टास्क पूरा के रूप में चिह्नित करें |
| ⌘⌫ | फ़ोकस वाली पंक्ति पर **टास्क हटाएँ…**; यह पहले पूछता है |

वैश्विक वर्कस्पेस कुंजियाँ todz › सेटिंग में **वर्कस्पेस शॉर्टकट** के तहत बदली जा सकती हैं। [वर्कस्पेस](/hi/workspaces) बताता है कैसे, और जब कोई दूसरा ऐप कोई कुंजी-संयोजन थामे हो तब क्या करें।
