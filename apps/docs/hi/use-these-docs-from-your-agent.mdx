---
title: इन डॉक्स को अपने एजेंट से इस्तेमाल करें
description: एजेंट को ये डॉक्स MCP या सादी टेक्स्ट फ़ाइल से दें।
---

इन डॉक्स का अपना MCP सर्वर है। Claude Code में:

```bash
claude mcp add --transport http todz-docs https://docs.todz.app/mcp
```

सादा टेक्स्ट पढ़ने वाले एजेंट के लिए [todz.app/llms.txt](https://todz.app/llms.txt) पेजों की सूची देता है और [todz.app/llms-full.txt](https://todz.app/llms-full.txt) उन्हें पूरा देता है।

इसके बजाय एजेंट को आपके टास्क पर काम कराने के लिए [एजेंट कनेक्ट करें](/hi/connect-an-agent) देखें।
