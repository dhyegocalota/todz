---

`https://api.todz.app/mcp` पर मौजूद todz MCP सर्वर क्लाइंट को MCP OAuth से साइन इन कराता है। अपने क्लाइंट में यह URL जोड़ें। पहली कॉल आपका ब्राउज़र खोलती है, और वहीं आप ऐप को मंज़ूरी देते हैं। कनेक्ट करने का एकमात्र तरीका OAuth है।

अगर आप अपना सर्वर चलाते हैं, तो `https://api.todz.app/mcp` की जगह उसका URL इस्तेमाल करें।

## ज़रूरी बदलाव: API कुंजियाँ हटा दी गईं

2026-11-27 को todz ने API कुंजियाँ हटा दीं। प्रोजेक्ट कुंजियाँ और मालिक कुंजियाँ काम करना बंद कर चुकी हैं, और सर्वर ने सहेजी गई हर कुंजी मिटा दी। जो क्लाइंट अब भी कुंजी भेजता है, उसे `401` मिलता है, जिसमें इसी पेज की ओर इशारा होता है।

कुंजी इस्तेमाल करने वाले एजेंट को दोबारा कनेक्ट करने के लिए `claude mcp add --transport http todz https://api.todz.app/mcp` चलाएँ और नीचे बताए अनुसार साइन इन करें। पुराना `Authorization` हेडर हटा दें, और अगर आपने `TODZ_API_KEY` वेरिएबल सेट किया था तो उसे भी। Mac ऐप की **एजेंट कनेक्ट करें** स्क्रीन भी इसी अपडेट में हट गई है।

## OAuth से साइन इन करें

1. अपना todz ईमेल डालें और जाँच पूरी करें।
2. मेल का साइन-इन लिंक **उसी ब्राउज़र में** खोलें।
3. सहमति स्क्रीन पढ़ें: उसमें ऐप का नाम होता है और यह भी कि वह आपको कहाँ वापस भेजता है।
4. एक प्रोजेक्ट चुनें। पहला पहले से चुना हुआ होता है। या **आपका पूरा खाता (मालिक स्कोप)** चुनें, जो कभी पहले से चुना नहीं होता और चेतावनी देता है: "यह हर टास्क पढ़ और बदल सकता है, और हर वर्कस्पेस और प्रोजेक्ट बना सकता है, उसका नाम बदल सकता है और उसे हटा सकता है।"
5. मंज़ूर करें, या अस्वीकार करें।

प्रोजेक्ट स्कोप टास्क टूल देता है, और `move` और `projects` के लिए उसी वर्कस्पेस के बाकी प्रोजेक्ट भी। मालिक स्कोप खाते के टूल देता है, और खाते के हर प्रोजेक्ट के लिए वही टास्क टूल, जिनमें से हर एक `project` id लेता है, जो `workspaces` से मिलता है। टास्क के इतिहास में ऐप का वही नाम दिखता है जो उसने रजिस्टर किया था। [MCP टूल](/hi/mcp-tools) देखें।

एक्सेस टोकन एक घंटे चलते हैं और अपने आप नए हो जाते हैं। रिफ़्रेश टोकन 30 दिन चलते हैं और हर इस्तेमाल पर बदल जाते हैं; 5 सेकंड के भीतर एक बार दोबारा कोशिश करने पर नई जोड़ी मिल जाती है, और इस्तेमाल हो चुका टोकन बाद में फिर इस्तेमाल करने पर ऐप डिसकनेक्ट हो जाता है। todz टोकन सिर्फ़ डाइजेस्ट के रूप में सहेजता है। उचित उपयोग और क्लाउड की सीमा हर कनेक्टेड ऐप पर लागू होती है।

किसी ऐप को डिसकनेक्ट करने के लिए Mac ऐप में **सेटिंग** › **कनेक्टेड ऐप** खोलें। ऐप उसी पल रुक जाता है।

रीडायरेक्ट पते `https` या लूपबैक पते (`127.0.0.1`, `localhost`, `[::1]`) होने चाहिए। कस्टम स्कीम मना कर दी जाती हैं, जैसा विनिर्देश माँगता है।

### Claude Code

```bash
claude mcp add --transport http todz https://api.todz.app/mcp
```

फिर Claude Code में `/mcp` चलाएँ और साइन इन करने के लिए todz चुनें। Claude Code ब्राउज़र खोल देता है।

### Claude.ai और Claude Desktop

**Settings** › **Connectors** › **Add custom connector** खोलें, URL के रूप में `https://api.todz.app/mcp` डालें, फिर **Connect** दबाएँ।

### Codex

इसे `~/.codex/config.toml` में जोड़ें:

```toml
[mcp_servers.todz]
url = "https://api.todz.app/mcp"
```

फिर साइन इन करें:

```bash
codex mcp login todz
```

### Cursor

Cursor MCP सर्वरों में `cursor://` पते से साइन इन करता है, जिसकी MCP विनिर्देश अनुमति नहीं देता और todz मना कर देता है। जब तक Cursor `https` या लूपबैक पते से साइन इन नहीं करता, वह todz से कनेक्ट नहीं हो सकता।
