# @todz/docs

The documentation site that Mintlify builds for the docs host: what todz is, getting the app and signing in, workspaces and their keys, connecting an agent, the MCP tools an agent gets, the guide to running your own server, what todz counts and the open source license. It describes the [Worker](../api/) and the [app](../macos/) for people and holds no product code of its own.
