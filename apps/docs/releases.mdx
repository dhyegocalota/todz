Every release is a GitHub tag named `mac-v<version>` at [github.com/dhyegocalota/todz/tags](https://github.com/dhyegocalota/todz/tags). The app reads [todz.app/download/appcast.xml](https://todz.app/download/appcast.xml) to update itself.

## 0.2.2

- Workspace shortcuts: ⌃1 … ⌃9, ⌃⌘[ and ⌃⌘], rebindable, from any app. See [Workspaces](/workspaces).
- Several workspaces at once, or **All Workspaces**, tagged by workspace.
- **Star todz on GitHub** in the popover and the todz menu, and **Open source on GitHub** in Settings.
- A background for the disk image.
- **Share anonymous usage**, off until you say yes. See [Privacy](/privacy).

## 0.2.1

No change to the app. It is the first update delivered through Sparkle, to check that a 0.2.0 install updates itself.

## 0.2.0

The first public download.

- The app updates itself through Sparkle. See [Updates](/updates).
- A workspace picker for accounts with several workspaces.
- Motion: the check draws in with a mint burst, the popover blooms, and the morning glance and day close slide in.
- A key revoked in Connect an Agent leaves the list at once.
- The menu bar ribbon, the day close, the morning glance and the day email.
