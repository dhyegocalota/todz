O todz é código aberto sob a [AGPL-3.0](https://github.com/dhyegocalota/todz/blob/main/LICENSE). O repositório inteiro tem uma só licença: o app, o servidor, as bibliotecas e esta documentação.

O código está em [github.com/dhyegocalota/todz](https://github.com/dhyegocalota/todz). Se o todz for útil para você, escolha **Dar estrela ao todz no GitHub** no popover ou no menu do todz. **Código aberto no GitHub** em todz › Ajustes também abre o repositório.

## Contribua

Leia primeiro o [CONTRIBUTING](https://github.com/dhyegocalota/todz/blob/main/.github/CONTRIBUTING.md). As contribuições vêm sob o [Contributor License Agreement](https://github.com/dhyegocalota/todz/blob/main/.github/CLA.md). Relate um problema de segurança como a [política de segurança](https://github.com/dhyegocalota/todz/blob/main/.github/SECURITY.md) pede, nunca em uma issue pública.

Para rodar o seu próprio servidor, veja [Auto-hospedagem](/pt-br/self-host).
