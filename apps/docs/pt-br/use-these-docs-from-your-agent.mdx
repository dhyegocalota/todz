---
title: Use esta documentação com o seu agente
description: Dê esta documentação a um agente por MCP ou por um arquivo de texto simples.
---

Esta documentação tem o seu próprio servidor MCP. No Claude Code:

```bash
claude mcp add --transport http todz-docs https://docs.todz.app/mcp
```

Para um agente que lê texto simples, [todz.app/llms.txt](https://todz.app/llms.txt) lista as páginas e [todz.app/llms-full.txt](https://todz.app/llms-full.txt) traz todas elas por completo.

Para deixar um agente trabalhar nas suas tarefas, veja [Conectar um agente](/pt-br/connect-an-agent).
