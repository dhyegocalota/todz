---
title: Atalhos de teclado
description: As teclas das listas e dos workspaces.
---

| Teclas | Ação |
| --- | --- |
| ⌘N | **Nova tarefa** |
| ⇧⌘N | **Novo projeto…** |
| ⌘R | **Atualizar** |
| ⌥⌘I | **Mostrar inspetor** e **Ocultar inspetor** |
| ⌘⌫ | **Excluir tarefa…** na tarefa selecionada, na lista de tarefas; o todz pergunta antes |
| ⌘K | **Trocar de workspace…**, que pede Touch ID quando o bloqueio está ativo |
| ⌘1 … ⌘9 | Trocar de workspace no popover e no menu de workspaces |
| ⌃1 … ⌃9 | Ir para o workspace 1 … 9, com o todz em primeiro plano |
| ⌃⌘[ | **Workspace anterior**, com o todz em primeiro plano |
| ⌃⌘] | **Próximo workspace**, com o todz em primeiro plano |
| ⌃⌥⌘1 … ⌃⌥⌘9 | Ir para o workspace 1 … 9, de qualquer app, quando **Alternar de qualquer app** está ativado (desativado por padrão) |

No popover da barra de menus:

| Teclas | Ação |
| --- | --- |
| ⌘O | Abrir o todz |
| ⌘N | Focar em **Adicionar uma tarefa** |
| ↓ e ↑ | Percorrer o cartão, as linhas e **Concluídas hoje** |
| Espaço | Concluir a tarefa, ou reabri-la |
| Return | Mostrar a tarefa na janela do todz |
| ⌘↩ | Concluir a tarefa de **A seguir**, a partir de **Adicionar uma tarefa** |
| ⌘⌫ | **Excluir tarefa…** na linha em foco; o todz pergunta antes |

As teclas globais de workspace podem ser reatribuídas em **Atalhos de workspace** em todz › Ajustes. [Workspaces](/pt-br/workspaces) explica como, e o que fazer quando outro app já usa uma combinação.
