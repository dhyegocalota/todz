---
title: MCP tools
description: The tools and the prompt an agent gets from the todz MCP server, and the scope each one needs.
---

An MCP client connects to the todz server with OAuth only: add the URL to your client and sign in, as [Connect an agent](/connect-an-agent) shows. The grant you approve picks the tool set: a project scope gets the task tools, and an owner scope gets the account tools. Each tool below names the scope it needs.

- A **project scope** holds the to-do list of one project: the project you picked on the consent screen. It can also list and move tasks inside the workspace of that project. It never creates, renames or deletes a workspace or a project. Task ids look like `T-12`.
- An **owner scope** manages the account: its workspaces and projects. It is never preselected on the consent screen, and you disconnect it in **Settings** › **Connected apps**. It reaches no task and no other account. Connect it under its own name, `todz-account`, so it sits beside the `todz` server of a project instead of replacing it.

An agent with a project scope does not see the owner tools, and an agent with an owner scope does not see the task tools. Every delete asks for a `confirm` argument holding the current name (a task's current title); when it differs, nothing is deleted.

## next

**Scope:** project scope.

The one open task to work on now in this project, with its notes.

It takes no arguments.

## add

**Scope:** project scope.

Add one or more tasks. Give each an idempotency_key to make a retry safe.

| Argument          | Type           | Description                                                                  |
| ----------------- | -------------- | ---------------------------------------------------------------------------- |
| `tasks`           | list           | The tasks to add, one object each.                                           |
| `title`           | text           | Short title.                                                                 |
| `notes`           | text or null   | Markdown notes.                                                              |
| `due_date`        | text or null   | Calendar date, YYYY-MM-DD.                                                   |
| `idempotency_key` | text or null   | Any string unique to this task; repeating it returns the task already added. |

## list

**Scope:** project scope.

List tasks by state, due window and text, in manual order (done: newest first).

| Argument | Type            | Description                                                                            |
| -------- | --------------- | -------------------------------------------------------------------------------------- |
| `state`  | text            | `open` or `done`. Defaults to `open`.                                                  |
| `due`    | list of text    | Due windows to include: `overdue`, `today`, `upcoming` or `undated`. Empty means all. |
| `text`   | text or null    | Text to find in titles and notes.                                                      |
| `limit`  | whole number    | How many tasks to show.                                                                |

## show

**Scope:** project scope.

Show one task with its state, due date and notes.

| Argument | Type   | Description           |
| -------- | ------ | --------------------- |
| `id`     | text   | Task id, like `T-12`. |

## history

**Scope:** project scope.

Show what happened to a task, oldest first: who did what and when.

| Argument | Type   | Description           |
| -------- | ------ | --------------------- |
| `id`     | text   | Task id, like `T-12`. |

## update

**Scope:** project scope.

Change a task's title, notes, due date or place in the order. null clears notes or the due date.

| Argument    | Type           | Description                                                                |
| ----------- | -------------- | -------------------------------------------------------------------------- |
| `id`        | text           | Task id, like `T-12`.                                                      |
| `title`     | text           | Short title.                                                               |
| `notes`     | text or null   | Markdown notes.                                                            |
| `due_date`  | text or null   | Calendar date, YYYY-MM-DD.                                                 |
| `placement` | object         | Where to move the task: `first`, `last`, or `before` or `after` an anchor. |
| `kind`      | text           | Inside `placement`: `first`, `last`, `before` or `after`.                  |
| `anchor`    | text           | Inside `placement`, with `before` and `after`: the id of the other task.   |

## done

**Scope:** project scope.

Complete one or more tasks, with an optional note of what was done.

| Argument | Type           | Description                |
| -------- | -------------- | -------------------------- |
| `ids`    | list of text   | Task ids, like `T-12`.     |
| `note`   | text or null   | What was done.             |

## reopen

**Scope:** project scope.

Reopen one or more done tasks.

| Argument | Type           | Description                |
| -------- | -------------- | -------------------------- |
| `ids`    | list of text   | Task ids, like `T-12`.     |

## delete

**Scope:** project scope.

Delete a task for good. Give its current title as confirm; nothing is deleted when it differs. A task you mean to keep somewhere else needs move. The owner's Mac shows the deletion after its next update.

| Argument  | Type   | Description                                                                |
| --------- | ------ | -------------------------------------------------------------------------- |
| `id`      | text   | Task id, like `T-12`.                                                      |
| `confirm` | text   | The current title of the task, typed exactly. Nothing is deleted when it differs. |

## move

**Scope:** project scope.

Move a task to another project of the same workspace. The task gets a new id there. Find project ids with projects. The owner's Mac shows the move after its next update.

| Argument  | Type   | Description                                                      |
| --------- | ------ | ---------------------------------------------------------------- |
| `id`      | text   | Task id, like `T-12`.                                            |
| `project` | text   | Id of the project to move the task to, from the projects tool.   |

## projects

**Scope:** project scope.

List the projects of the workspace this connection belongs to, with their ids.

It takes no arguments.

## workspaces

**Scope:** owner scope.

List the workspaces of this account with their projects and ids.

It takes no arguments.

## create_workspace

**Scope:** owner scope.

Create a workspace. It starts with an Inbox project.

| Argument | Type   | Description                         |
| -------- | ------ | ----------------------------------- |
| `name`   | text   | Name, up to 80 characters.          |

## rename_workspace

**Scope:** owner scope.

Rename a workspace.

| Argument    | Type   | Description                         |
| ----------- | ------ | ----------------------------------- |
| `workspace` | text   | Id of the workspace, from workspaces. |
| `name`      | text   | Name, up to 80 characters.          |

## delete_workspace

**Scope:** owner scope.

Delete a workspace for good with all its projects and tasks. Give its current name as confirm; nothing is deleted when it differs.

| Argument    | Type   | Description                                                                          |
| ----------- | ------ | ------------------------------------------------------------------------------------ |
| `workspace` | text   | Id of the workspace, from workspaces.                                                |
| `confirm`   | text   | The current name of the workspace, typed exactly. Nothing is deleted when it differs. |

## create_project

**Scope:** owner scope.

Create a project in a workspace.

| Argument    | Type   | Description                         |
| ----------- | ------ | ----------------------------------- |
| `workspace` | text   | Id of the workspace, from workspaces. |
| `name`      | text   | Name, up to 80 characters.          |

## rename_project

**Scope:** owner scope.

Rename a project. The Inbox cannot be renamed.

| Argument  | Type   | Description                         |
| --------- | ------ | ----------------------------------- |
| `project` | text   | Id of the project, from workspaces. |
| `name`    | text   | Name, up to 80 characters.          |

## delete_project

**Scope:** owner scope.

Delete a project for good with its tasks. Give its current name as confirm; nothing is deleted when it differs. The Inbox cannot be deleted.

| Argument  | Type   | Description                                                                         |
| --------- | ------ | ----------------------------------------------------------------------------------- |
| `project` | text   | Id of the project, from workspaces.                                                 |
| `confirm` | text   | The current name of the project, typed exactly. Nothing is deleted when it differs. |

## settings

**Scope:** owner scope.

Show the account settings: time zone, agent nudge and day email.

It takes no arguments.

## update_settings

**Scope:** owner scope.

Change the account settings. Give only what changes.

| Argument            | Type            | Description                                                                              |
| ------------------- | --------------- | ---------------------------------------------------------------------------------------- |
| `time_zone`         | text            | Time zone name, like America/Sao_Paulo.                                                  |
| `agent_nudge`       | true or false   | Whether next adds a line about the tasks due today.                                      |
| `day_email`         | true or false   | Whether the day email is sent.                                                           |
| `day_email_minutes` | whole number    | Minutes after midnight, in your time zone, when the day email is sent: 0 to 1439.        |

## Prompts

The server offers one prompt, `next`: Start working on the next task of this project.
