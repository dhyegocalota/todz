# 0114. One motion system maps each moment to a token, and Reduce Motion turns it into a crossfade or an instant change

- Status: Accepted (the loop's call)
- Date: 2026-11-27
- Deciders: Claude (the build loop's call, under the owner's order "faça as animações cinematográficas no app, no menubar, no widget etc.. mas smooth e quem quer redução de animação, respeite ok")
- Inspired by: [0077](0077-the-motion-system-is-one-token-set-in-todzkit-with-every-effect-under-350-ms-and-a-crossfade-under-reduce-motion.md), [0106](0106-the-count-rolls-in-template-frames-new-rows-spring-in-by-identity-and-the-title-flies-by-measured-origin.md), [0061](0061-performance-has-written-budgets-a-fetch-based-load-harness-behind-pnpm-perf-and-work-count-budgets-in-verify.md), `docs/features/menubar-redesign/design.md` § 12

The loop's call: views name a moment (`MotionMoment`: list insert, complete, reorder, workspace switch, press, count change and the rest) and `MotionSpec.of(_:isReduceMotionOn:index:)` in TodzKit answers its token, transform and delay, so no view picks numbers and a unit test reads every answer with Reduce Motion on and off. A new `press` token (a 0.97 scale on a spring of response 0.075, 150 ms because that spring settles in 149 ms) joins the seven. A workspace switch cascades the first six rows 12 ms apart with `snap`, so the whole choreography ends at 260 ms, under the 350 ms ceiling, and only when the identity set of a different list replaces the last (`RowArrival`), never on scroll. This amends ADR 0077 point 3: with Reduce Motion on a moment is either a 150 ms crossfade or an instant change, never a scale, an offset, a stagger or a burst, and the pure geometry moments (reorder, press, hover, focus) are instant because a crossfade of a move draws a row twice. The widget ring stays static because WidgetKit cannot interpolate a custom trim; its number rolls and its checkbox glyph replaces through the same modifiers. A repository-shape test fails when a view animates outside the TodzKit motion modifiers. Frame rate is measured by hand with Instruments, never gated, and the work counts of ADR 0061 do not change.
