# 0128. A click switches, adding is explicit, and a locked session keeps the set it locked with

- Status: Accepted (the loop's call)
- Date: 2026-11-27
- Deciders: Claude (the build loop's call, under the owner's orders of 2026-11-27: "queremos suportar múltiplos workspaces!!! não tire esta opção" and "com trava ligada posso selecionar múltiplos.. mas daí quando travado, não posso ver outros")
- Inspired by: [0080](0080-the-workspace-picker-selects-several-workspaces-or-all-and-every-surface-shows-their-union-tagged-by-workspace.md), [0110](0110-the-workspace-lock-hides-every-workspace-but-the-current-one-until-touch-id-or-the-mac-password-unlocks-a-session.md), [0113](0113-a-locked-session-looks-like-a-one-workspace-account-with-no-placeholder-count-or-lock-chrome-and-one-neutral-way-back-in.md)
- Amends: [0122](0122-the-workspace-lock-switch-on-shows-one-workspace-and-refuses-widening.md), whose "one workspace while the switch is on" no longer holds

The loop's call: everywhere, with the lock on or off, a plain click on a switcher row shows that workspace alone, and showing several is explicit. Command-click on a row, or a row of the Show Alongside submenu, adds a workspace to the view or takes it out. Rows carry a checkmark for each workspace in view, and All Workspaces is offered whenever more than one workspace is visible. `AppModel.pickWorkspace` makes this decision from the gesture; no view decides. With the lock off, several workspaces work as before. With the lock on, an unlocked session selects one, several or All freely. When the session locks (sleep, screen lock, screensaver, idle, Lock Now, quit), it keeps the set selected at that moment, even when the set holds several workspaces, and All is pinned to the workspaces it held so that a later workspace never joins. A launch opens the last selected set and never more. While locked, every workspace outside the set disappears from every surface, as ADR 0113 requires: switcher, menus, shortcuts, global hot keys, intents, links, the popover, the widget snapshot, Connected apps and the cache. Switching within the set or removing a workspace from it asks nothing. Adding, switching to or selecting All toward any workspace outside the set asks Touch ID or the Mac password first, and a refused prompt changes nothing. A locked session with N workspaces looks exactly like an account that holds those N. The widgets carry the whole set, because the set is what stays visible when the session locks.
