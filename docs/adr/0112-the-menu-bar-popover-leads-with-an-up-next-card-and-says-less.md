# 0112. The menu bar popover leads with an Up next card and says less

- Status: Accepted (the loop's call)
- Date: 2026-11-27
- Deciders: Claude (the build loop's call under the owner's order "Menu bar redesign", 2026-11-27)
- Inspired by: the owner's ask, "faz o menubar ficar muito mais sexy, conciso e útil"; amends [the menu bar design](../features/menu-bar/design.md) options O3 and O10; follows [0104](0104-forms-share-one-drawn-field-language-on-native-buttons-and-a-glass-panel.md), [0077](0077-the-motion-system-is-one-token-set-in-todzkit-with-every-effect-under-350-ms-and-a-crossfade-under-reduce-motion.md)

The loop's call: the popover is option C of [the redesign](../features/menubar-redesign/design.md), "Up next". The header carries the workspace, a day ring with the count, an Open button and a More menu that takes Quit, Check for Updates, Star on GitHub and the update note off the foot, which is gone; a glass composer sits at the top; the first open task is a card, the rest is a quiet queue of one-line rows, and the tasks done today sit behind a collapsed disclosure. One pure model in TodzKit (`MenuBarDay`, `MenuBarRowMeta`, `MenuBarNavigation`, `MenuBarNotice`) decides the screen, the rows' words, the arrow-key targets and the strip under the header, so the views only draw it. This amends menu-bar O3 (done-today rows are no longer listed after the open rows; they open from `Done today`) and O10 (a compact row: the `T-n` id shows only on hover and focus, because it is ambiguous across projects, and the project shows only when it is not the Inbox). Two keys change: ⌘O opens todz and replaces ⌘0, which was rarely learned, and Space completes the focused task where it used to open the window (Return still opens it); ⌘↩ completes the Up next task from the composer. The ring and the update dot are the two measures `FormMetrics` cannot express, so they live in `MenuBarMetrics`. Type-to-add is left for a later version.
