## How to run

```bash
pnpm install --frozen-lockfile
PORT=$(node -e "require('net').createServer().listen(0,'127.0.0.1',function(){console.log(this.address().port);this.close()})")
pnpm --filter @todz/docs run dev --port $PORT --no-open
```

Open `http://localhost:$PORT` (the introduction), `/quickstart`, `/connect-an-agent`, `/mcp-tools`, `/self-host`, `/no-such-page`. `mint` 4.3.91 is a dev dependency installed by `pnpm install`; the first run downloads the client `0.0.4077` (needs the network). Gate pieces, from the repository root:

```bash
pnpm --filter @todz/docs broken-links     # success no broken links found
pnpm --filter @todz/docs validate         # exit 0
pnpm --filter @todz/docs test:walk        # 32 passed, 6 skipped (38 tests: 6 are viewport-specific)
pnpm --filter @todz/repository-shape exec vitest run
pnpm --filter @todz/api test:unit && pnpm --filter @todz/api site:check
pnpm test:verify                          # about four minutes: it builds many throwaway repositories
```

The walk picks its own free port (`TODZ_DOCS_PORT`, set once by `docsPortOf` and read by the workers).

4. Hypothesis: the pinned client renders every page with a clean console at 1280 and 375, light and dark. Break it by: running the walk with the allow-list disabled again; bumping `--client-version` to `0.0.4318` and watching for `__dirname`.
5. Hypothesis: no page links into the repository and the guide parses as MDX. Break it by: adding `[x](https://github.com/dhyegocalota/todz/blob/main/README.md)` or a bare `<` in prose in the guide.

7. Hypothesis: the MCP reference lists exactly the arguments of the schemas. Break it by: adding a field to `UpdateArgumentsSchema` or `PlacementSchema`.
