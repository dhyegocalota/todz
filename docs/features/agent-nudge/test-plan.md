## Adversarial review

The reviewer picks the three claims most likely to be wrong and tries to refute each.

- [x] Claim 1: the line always names the task the same `next` answer shows, and that task is due now — attack: a write between the `nextTask` and `dueNow` reads (two transactions), for example an undated T-5 returned, then T-6 due today added; result: refuted on paper (`Today here: 1 due.
