## Coverage honesty

What is not tested and why.

- A request's `Content-Type` is not read: a JSON body is parsed whatever the header says. Accepted for v1, because the only client is the app; no test pins it.
- The runtime, not the Worker, answers a socket request that sends `Upgrade: websocket` without the handshake headers (426 with its own text), and `wrangler dev`'s local proxy drops the `Upgrade` header of the Worker's 426. Both are outside the Worker's code; the unit test inside workerd pins the Worker's own answer.
- Socket lifetime and count: an open socket outlives the session that opened it, and sockets per project are not capped (security review MINOR 2). Deferred to the loop's questions.
- Request body size: a huge JSON body is parsed before the core's batch limits (security review MINOR 4). Deferred to the loop's questions.
- The fake provider rests on one variable; a second loopback check was not added (security review MINOR 1). Deferred: v1 never deploys, and the Apple adapter replaces it before any deploy.

- The Apple verifier — not built in v1 (ADR 0020).
- Socket behaviour across a real Durable Object hibernation and wake — the pool runs the object in one process; the hibernation API is used as documented, and the tester's `wrangler dev` walk is the closest proof.
- Load: many sockets per project, large first pulls — no budget is set for v1.
