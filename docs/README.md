# Project documents

How todz is built and run.

| Folder | What it holds |
| --- | --- |
| [adr](adr/) | Architecture decision records: each decision, the options rejected and when to revisit it |
| [features](features/) | One folder per feature or fix, with its spec, plan and test plan, and a status index |
| [product](product/) | The approved v1 product design and its mockups, the source every feature spec is cut from |
| [learnings](learnings/) | Dated traps that cost time, and the move that avoids them |
| [runbooks](runbooks/) | Step-by-step procedures a person follows by hand |
| [screenshots](screenshots/) | The product screenshots the root README walks, one folder per visible feature |
| [scenarios](scenarios/) | Agentic walks of the product core in real browsers, one file per flow |
